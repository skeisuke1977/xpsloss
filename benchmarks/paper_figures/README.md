## 数値計算の条件

別担当者の閉形式の実装を移植した。`model.py` の `eq20` が原著の Al の応答（ħωp = 15.6 eV）、`split` が法線から0°の式(13)–(17)である。electron は正孔電荷0での断面積、hole は電荷1の全量から electron を引いた符号付き成分。数値積分は log(k∥) の複合 Gauss–Legendre 則で行う。各ラベルについて、ε の引数を k∥ と √(k∥² + Ω₀²) にそれぞれ設定して計算する。

例として、図5(a,b)の 200 eV、幅 2.1 eV の全曲線は、同じルートから次のように計算できる。各配列の列順は electron、hole。

```python
import numpy as np
from benchmarks.paper_figures.model import MOMENTA, split

losses = np.arange(1, 301) / 10
curves = {q: np.array([split(200, t, 10, 2.1, q) for t in losses]) for q in MOMENTA}
```

## 読取りと判定

図3は各深さとバルクの曲線を凡例で特定し、約15.7 eV の頂点を縦軸の目盛りから目視で読んだ。高さの読取り誤差は ±0.001 eV⁻¹ Å⁻¹。図5・8ではレビュー担当が原図を400 dpiで読み、縦横の目盛り間隔でピクセル座標を較正した。図5(a,b)の横軸は約26.1 px/eV、縦軸の0.01はそれぞれ222.75、195 px。図8の横軸は約30.9 px/eV、縦軸の0.005は161.5 px。自分の原著で追加の点を読む際は、指定損失を通る縦線上で黒線の中心を取り、頂点の位置・高さは曲線を分離できる列で求める。ラベルと曲線が接する箇所は線を左右にたどる。

図5・8の高さ・尾部は線幅から ±0.0002 eV⁻¹ Å⁻¹、位置は ±0.1 eV と見積もった。図8の全量ピークの読取り範囲 0.0161–0.0163 には中点を使った。図5(b)の 2000 eV ピークは上位の曲線が重なり、対応づけに不確かさがある。固定損失点と格子ピークだけを照合し、全曲線の一致率は計算していない。

各幅・運動量で、絶対差が読取り誤差以下なら CSV の `*_within` が真になる。幅と運動量は一つの読取りを繰り返し照合する条件なので、集計の分母は読取り点の数とした。

1. 少なくとも一方の運動量で幅を変えると内外が変わる点は「幅の仮定に依存」とする。
2. 内外が変わらず、少なくとも一方の運動量で誤差を超える点は「誤差外」とする。仮定した幅が一つだけのときも、その幅での差を記録する。
3. 両運動量が誤差内でも、Table I に該当する E₀ がなく幅を一つしか試していない点は「幅の仮定に依存」とする。それ以外の両運動量が誤差内の点は「読取り誤差内」とする。いずれも表に掲げた条件での判定である。
