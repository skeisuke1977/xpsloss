図・パネル・E₀・深さ・成分・量・損失エネルギーで一つの比較点を特定する。ピーク高さと位置は別の点として数える。高さと損失固定値の単位は eV⁻¹ Å⁻¹、ピーク位置は eV。各運動量の `*_grid` は精密化前の格子ピーク、`*_margin` は |計算値 − 読取り値| − 読取り誤差で、正なら誤差外である。

## 数値計算の条件

別担当者の閉形式の実装を移植した。`model.py` の `eq20` が原著の Al の応答（ħωp = 15.6 eV）、`split` が法線から0°の式(13)–(17)である。electron は正孔電荷0での断面積、hole は電荷1の全量から electron を引いた符号付き成分。数値積分は log(k∥) の複合 Gauss–Legendre 則で行う。各ラベルについて、ε の引数を k∥ と √(k∥² + Ω₀²) にそれぞれ設定して計算する。

| 図 | 計算条件 |
|---|---|
| 3 | E₀ = 1000 eV、深さ2・10・50 Åの全量。48パネル×16点、13–25 eV のバルクプラズモンを0.05 eV 刻みで探索する。無限媒質は式(1)、8–25 eV、1000パネル×40点。式(1)は積分変数が一つなので両運動量欄は同値になる。 |
| 5 | 深さ10 Å、96パネル×16点。表面ピークは 10 < T < 12、バルクピークは 14 < T < 17（電子）または 14 < T < 17.5（正孔）を0.1 eV 刻みで探索する。各幅で両運動量の曲線を個別に計算する。 |
| 8 | E₀ = 1413.5 eV、λ = 25.4 Å。式(18)の深さ平均 ∫t exp(−t) K_eff(λt) dt、t = x/λ を図の検算用に実装した。0–40 を `depth_average` の12区間に分け各6点、各深さで48パネル×16点。ピークは 14 < T < 17.5 を0.25 eV 刻みで探索する。 |

すべてのピークで、格子最大の左右の格子点を境界として連続曲線を最大化する（有界法、位置の絶対停止許容幅 10⁻⁸ eV）。その位置に最も近い 0.0001 eV 格子点と両隣の3点で放物線の頂点を求め、位置を 0.000001 eV に丸めて曲線の高さを再計算する。有界法と3点法の差が位置 10⁻⁵ eV、高さ 10⁻¹⁰ eV⁻¹ Å⁻¹ を超えたら生成を中止する。これらは計算曲線上の頂点を求める精度である。

**線幅 ħγ₀ の選択。** 全図で Table I の (E₀, ħγ₀) = (175, 3.4)、(300, 2.8)、(500, 2.1)、(1180, 1.5)、(2000, 1.3)（いずれも eV）を使う。掲載エネルギーではその幅1つ、掲載値の間では直近の上下2点の幅と E₀ に対する線形補間値の3つを判定に用いる。2000 eV より上では 1.3 eV だけを仮定する。補間値は途中で丸めない。幅の出所は CSV の `width_source` に示す。図5の200 eVで図に合うと分かった後に試した 2.1 eV、図3の 1.6・1.7 eV は `sensitivity (post hoc)`、`policy_width=False` として感度確認用に残した。

例として、図5(a,b)の 200 eV、幅 2.1 eV の全曲線は、同じルートから次のように計算できる。各配列の列順は electron、hole。

```python
import numpy as np
from benchmarks.paper_figures.model import MOMENTA, split

losses = np.arange(1, 301) / 10
curves = {q: np.array([split(200, t, 10, 2.1, q) for t in losses]) for q in MOMENTA}
```

## 読取りと判定

図3は各深さとバルクの曲線を凡例で特定し、約15.7 eV の頂点を縦軸の目盛りから目視で読んだ。高さの読取り誤差は ±0.001 eV⁻¹ Å⁻¹。図5・8ではレビュー担当が原図を400 dpiで読み、縦横の目盛り間隔でピクセル座標を較正した。図5(a,b)の横軸は約26.1 px/eV、縦軸の0.01はそれぞれ222.75、195 px。図8の横軸は約30.9 px/eV、縦軸の0.005は161.5 px。自分の原著で追加の点を読む際は、指定損失を通る縦線上で黒線の中心を取り、頂点の位置・高さは曲線を分離できる列で求める。ラベルと曲線が接する箇所は線を左右にたどる。

図5・8の高さ・尾部は線の太さから ±0.0002 eV⁻¹ Å⁻¹、位置は ±0.1 eV と見積もった。図8の全量ピークの読取り範囲 0.0161–0.0163 には中点を使った。図5(b)の 2000 eV ピークは上位の曲線が重なり、対応づけに不確かさがある。集計の対象は表に掲げた固定損失点とピークである。

各幅・運動量で、絶対差が読取り誤差以下なら CSV の `*_within` が真になる。判定には `policy_width=True` の行だけを使い、同じ読取りは一度だけ数える。総合判定では両運動量を、運動量別判定では対象の運動量だけを次の順で評価する。

1. 対象の運動量のいずれかで、幅を変えると内外が変わる点は「幅の仮定に依存」とする。
2. 内外が変わらず、対象の運動量のいずれかが誤差を超える点は「誤差外」とする。
3. すべて誤差内なら「読取り誤差内」とする。ただし E₀ > 2000 eV では幅を一つだけ仮定しているため、「幅の仮定に依存」とする。
