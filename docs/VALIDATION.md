# この配布物の検証記録

検証日: 2026-11-19。

## 実行環境

- Linux
- Python 3.12.14
- NumPy 2.3.5
- SciPy 1.17.0
- パッケージ版 0.0.1
- モデルID `bulk_drude_lindhard_v0`

## 自動テスト

開発ツリーで実行:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

結果: **12テスト、全合格**。最終実行は約4.4秒。実行時間はこの環境での参考であり、他機種の速度を保証しない。

| 検証 | 内容 |
| --- | --- |
| 無分散の解析解 | 3つの電子エネルギーと4つの損失エネルギーでlog(q+/q-)の解析式と一致 |
| 振動子の一次モーメント | ギャップなし、3種類の幅で積分値がpi A/2と一致 |

| 無損失とギャップ | 振動子強度ゼロ、ギャップ以下で損失ゼロ |
| 単位と運動量上下限 | eV/Åの換算と微小損失での桁落ち回避を確認 |
| 入力の失敗 | 不適切な物理値、未知キー、重複キー、非有限数を拒否 |
| CLI | capabilities、validate、elf、bulk、CSV/JSON出力、入力ハッシュを確認 |
| 上書き防止 | 既存出力への書込みを拒否 |
| 条件の再利用 | 出力に保存するconfigを、そのまま厳格なパーサーで読み直せる |

## パッケージとしての実行

wheelのビルドに成功し、別の仮想環境にそのwheelをインストールした。数値ライブラリは既存環境を共有した。その後、ソースディレクトリ外から、インストールされた `xpsloss` コマンドで合成例の160点を計算し、`bulk.csv` と `run.json` が生成されることを確認した。

## 再計算用の数値例

付属 `examples/synthetic_bulk.json` の入力SHA-256:

```text
b95c880c4c032ce1841f7bab524ad2e8340dc9af8f6dc7bdd2efff04f4cad134
```

電子の初期運動エネルギーは1000 eV。単一振動子の中心15 eV、強度180 eV²、幅2 eV、分散0.5、ギャップ0 eVの**合成例**である。

| --- | --- | --- |
| 1 | 2.1269512867869534e-5 | 4.5830768947853175e-16 |
| 15 | 6.351182297592145e-3 | 3.2285872377239254e-14 |
| 20 | 1.0667935151025684e-3 | 1.2644223304885299e-12 |
| 50 | 5.29875020524528e-5 | 1.2443694780201946e-13 |

この桁数は計算再現用であり、物性値の実験的精度を表すものではない。積分誤差はモデル仮定・入力値・物理定数の不確かさを含まない。OSや数値ライブラリが異なる場合の最終桁までの一致は要求しない。

## 独立レビュー

実装担当とは別の担当が、ELF、DIIMFP、運動量上下限、単位、解析基準、未実装範囲の記述を確認した。重大な誤りは指摘されなかった。これは下記の外部検証に代わるものではない。

- Al/Si/Au/CoO等の実材料に対する妥当性。
- Windows/macOS実機、Python 3.10/3.11など他のランタイムでの動作。
- 複素epsilon、表面、静止正孔、干渉、深さ平均、多重散乱、全スペクトル。
- CoOへのQuanty接続、非局所遮蔽の識別、実測フィッティング。

この配布物は、完全モデルの実装と検証に進むための、範囲を限定した参照コードである。
