## 段階4a 数値の頑健性（2026-11-20）

所有者のレビューで、非常に狭い共鳴を含む入力に対し、数値積分が誤った値を成功として返すことが分かった（[ROADMAP](ROADMAP.md) §3.3 R1・R1′）。段階4aで、バルク、誘電応答（ギャップのない振動子、ギャップのある KK、表形式の KK、補助の閉形式）、光学和則、固定深さの数値法を直した。物理モデル（式、既定値、単位、定数）は変えていない。実装は Codex、レビューは実装担当とは別のエージェント（Claude Opus）が行った。

**方法の要点:**
- 修正の前に、回帰試験の入力、参照値、許容誤差を固定した（`tests/test_numerics_4a.py`、`test_numerics_followup.py`、`test_numerics_followup2.py`）。各ファイルは編集前に複写し、最終版とのバイト一致を確かめた。凍結後の変更は1件だけで、既存の出力先を指定したときの CLI の期待状態を `error` に改めた（統括担当の判断。「成功の記録を残さない」という条件は変えていない）。
- 参照値は、実装とは別の経路で mpmath（80桁）を使って計算し、試験にはリテラルとして埋め込んだ。生成スクリプトは `benchmarks/numerics/` にある（mpmath が必要。CI では実行しない）。
- 許容誤差: バルクの K は max(10⁻¹² Å⁻¹ eV⁻¹, 10⁻⁷|K_ref|)、次元のない応答（Re F、Im F、和則の左辺）は成分ごとに max(10⁻⁹, 10⁻⁷|ref|)、一次モーメントは max(10⁻⁸ eV², 10⁻⁷|ref|)。
- 数値的に解像できない有効な入力は、経路ごとの未収束の例外（共通の基底は `NumericalConvergenceError`）で止まる。CLI は終了コード2と `not_converged` を返し、成功の記録（`run.json`）を書かない。判定は、線幅と端までの距離を座標の丸めや区間の分解能と比べて行い、線幅だけの一律のしきい値は使わない。

**結果:**

| 対象 | 結果 |
| --- | --- |
| 所有者のレビューの例（狭い線と広い線の混合、E0 = 1000 eV、T = 20 eV） | バルクの K = 8.886223592291592×10⁻⁴ Å⁻¹ eV⁻¹。有限幅の参照との相対差 1.3×10⁻¹⁵（修正前は 3.82×10⁻⁵ で、`complete` を返していた） |
| 事前の走査で作った反例 1,437 件（バルク、ギャップのある KK、光学和則、表形式の KK、固定深さの 13a） | 1,055 件が許容内で成功、382 件が未収束。許容外の値を成功として返した例は0件（修正前は 109 件） |
| レビュー担当の追加の走査（独自の参照による） | バルク、固定深さの全8項、光学和則、ELF、表形式とギャップのある KK で、許容外の成功は0件。ほぼ縮退した2本の極狭線が実部で打ち消し合う 3,000 組も、許容外の成功は0件（未収束 559 組）。補助の閉形式は、このように打ち消し合う入力では未収束を返し、数値 KK を使うよう案内する（同じ入力を数値 KK で計算すると、すべて許容内） |

| 自動テスト | 94件（既存75件と新規19件）が合格した。Windows、Python 3.12.10、NumPy 2.5.5、SciPy 1.18.1 と、Windows、Python 3.10.22、NumPy 1.24.0、SciPy 1.10.0（宣言した最低版） |

**残る限界:**
- ギャップのある KK で、積分する側の共鳴の幅や端までの距離が座標の丸めに比べて小さすぎる場合は、未収束で止まる（解かずに検出する）。
- 固定深さで、運動量の座標で分解できない線が1本でもあると、その線の強度によらず8項すべてを未収束とする。弱い線でも、旧版では 13a が参照の 5.3 倍になる例があったためである。
- 極端に狭い線（例: 幅 10⁻³⁰⁰ eV）では、既定の分割数の上限に初期の区間が入りきらず、入力エラー（`ValueError`、CLI では `error`）になる。上限を上げれば計算できる。
- 検証の範囲は、固定した試験、追加の走査、同梱の入力とデータ集の材料である。任意の入力に対する誤差の上界を証明したものではない。

## 段階4b 近似と適用範囲の明示（2026-11-20）

固定深さの計算について、計算できる条件（0 < T < E0）と、数値で照合した条件を分けて出力に記録するようにした。あわせて、誘電応答の静的な診断の名前を、判定の中身に合わせて改めた。実装は Codex、レビューは実装担当とは別のエージェントが行った（判定は修正後に承認。指摘は反映した）。数値の結果は変えていない（段階4aの版と、出力の CSV がバイト単位で一致した）。

**照合した範囲（`FIXED_DEPTH_CHECKED_ENVELOPE`、`src/xpsloss/cli.py`）:**

| 量 | 範囲 | 根拠 |
| --- | --- | --- |
| max(T)/E0 | 0.1 以下 | E0 = 1000 eV（T = 100 eV まで）と 4000 eV（T = 400 eV まで）で、I3 と同じ独立経路と基準により、`k_parallel` の全8項と成分を照合する（分散0と分散1、深さ 10 Å、`tests/test_applicability_envelope.py`）。13a は I2 でも解析式と照合する |
| E0 | 1000–4000 eV | 両端で、尺度変換していない同じ振動子を、上と同じ独立経路で照合する。I8 の尺度変換（相似な系）は、単位の整合の検査である。`k_total` で分散のある入力の有限深さの全項は、どの E0 でも独立には照合していない |

- I3 の条件は E0 = 1000 eV、T = 5–30 eV（比 0.03 以下）、深さ 2・10・50 Å である。範囲の両端の照合は、レビュー担当の指摘を受けて段階4bで加えた。
- 原著の図5の 200–10000 eV は、本パッケージとは別のコード（式(20)の誘電関数）による追試なので、上の範囲には含めない。
- 範囲は、離れた入力での数値の照合をまとめたものである。範囲の内側でも、物理的な妥当性、実測との一致、任意の格子での収束は保証しない。
- 範囲で比べるのは max(T)/E0 と E0 だけである。深さ、材料、線幅、分散、正孔の電荷、損失の格子の下端は、範囲に含まれない。

**出力:** `xps-fixed-depth` の `run.json` に `applicability` を加えた。中身は、max(T)/E0、E0、ε の運動量の指定、仮定、上の範囲と根拠、範囲の内外（`within_checked_envelope`）、注記である。仮定は、原著の p. 1613 と式(3)による。t = 0 に電子と正孔が同じ点に突然生じる。正孔は静止し、寿命は無限である。電子は直線の軌道を、初期運動エネルギーで決めた一定の速度（非相対論）で進む。損失は E0 に比べて小さい（T ≪ E0）。表面は鏡面反射の模型で扱う。範囲を外れると、計算は `complete` のまま、`warnings` に外れた量と差を記し、「このリポジトリの数値の照合はこの入力を覆わず、物理的な適用も未検証」と書く。拒否はしない。同じ `run.json` の `diagnostics.velocity`（非相対論）は、名前の重なりを避けるため `diagnostics.kinematics` に改めた。`bulk`（運動量の上下限に E0 − T を使い、速度を固定しない）と `dielectric`（電子のエネルギーを使わない）には加えない。

**静的な診断の改名:** `DielectricDiagnostics.static_status`（`stable`／`marginal`／`unstable`）を `static_sign`（`negative`／`marginal`／`positive`）に改めた。判定の中身は、指定した q で、採用した振動子の表現の Re[−1/ε(q, 0)] を許容幅 τ0 と比べた符号である。`positive` は、この表現の ε に上半平面の極が生じることを意味し、応答を拒否する。材料の安定性を判定するものではない。拒否の規則と許容幅は変えていない。

**テスト:** 99件（段階4aの94件と新規5件）が合格した。Windows、Python 3.12.10、NumPy 2.5.5、SciPy 1.18.1 と、Windows、Python 3.10.22、NumPy 1.24.0、SciPy 1.10.0。新規の試験は、T/E0 = 0.9（E0 = 1000 eV）で `complete` と警告が出ること、範囲の内側で警告が出ないこと、境界の値、E0 の下限・上限の超過、2つの量の同時の超過を確かめる。範囲の両端（E0 = 1000 eV と 4000 eV、比 0.1 まで）で、`k_parallel` の全8項と成分を独立経路と照合する試験（`tests/test_applicability_envelope.py`、約18秒）も加えた。許容に対する誤差の比は、最大で 1000 eV が 5.6×10⁻¹⁰、4000 eV が 4.1×10⁻⁶ だった。成功時の標準出力には `warning_count` を加えた。

### QUEELS-XPS v2.1 との比較

- **§4.2 の比較:** Al（データ集、分散1）、1000 eV、深さ 9.967 Å で比べた。`k_parallel`、`k_total` のどちらも不合格だった。`total` は max の 6.6–7.5 % ずれ、`no_hole` と `hole` の分け方は大きく違った。
- **原因の切り分け:**

  - 深さ182 Å のバルク部分は、`k_total` で約0.1 % 一致した。
  - Codex、agy（Gemini 4 Neon）、Grok に、互いの回答を見せずに相談した。うち2者が同じ処方を挙げた。逆誘電関数の実部の分子に分散前の振動子エネルギーを使えば、参照出力を説明できるという仮説である。
- **事前登録試験:** この処方を、新しい3つの合成入力（γ = 0.75 eV、α = 0.25、2振動子）の計算の前に固定した。3つとも候補の処方が基準（max T の 3×10⁻³）を満たした。公表された式は満たさなかった（[QUEELS_DISPERSION_TEST.md](QUEELS_DISPERSION_TEST.md)）。
- **判断:** 本パッケージは公表された式（Yubero ら 1996 の式(32)、KK関係を満たす）を使い、候補式は実装しない（利用者の決定、2026-11-20）。試験した分散のある入力では、本パッケージの結果は QUEELS-XPS v2.1 の出力との比較基準を満たさなかった。参照ソフトの出力は公開しない（[NOTICES.md](../NOTICES.md)）。

### 独立レビューで確認した主な内容

- **M1-B:** KK関係の符号、係数2/π、F(∞)=−1、負周波数の折り返し、ギャップ端の対数発散係数 L0(q,Eg)/π、ギャップ下のεの実軸極、F(q,0)>0 で上半平面に極が生じる判定、幅Γが弱減衰の共鳴近傍で半値全幅になることを、レビュー担当が導出し直して一致を確認した。レビュー担当の独立参照2種との最大相対差は 2.7×10⁻¹⁰（狭い・広い振動子、端から10⁻¹⁰Egの点、q≤5、Al）、無作為300材料で 3.0×10⁻¹³。
- **M1-B の修正:** 格子点がギャップ端に重なる場合と、厳密に規格化された金属的入力（Σ A/E²=1）の判定が丸めに依存する場合の2件（major）を修正し、修正後の再確認で後退がないことを確かめた。ギャップ端の除外幅 10⁻¹²Eg は数値上の安全策であり、物理的な正則化ではない。その外側でも端に近い行は格子の位置で値が決まるため、10⁻³Eg 以内の点に個別の警告を出す。
- **M1-C:** データ集の3つの原本のSHA-256、Si・Au・Alの全数値と行番号が入力記録と一致した。Siの式(11)の数値と48材料の和則表もレビュー担当の独自コードで再現した。
- **M1-A（式の転記）:** Claude Fable と Codex が、互いの結果を見ずに原著のページ画像から全20式を転記した。両者は記号・符号・因子・べき・括弧の範囲まで一致し、判読不能の箇所はなかった。統括担当が式(13)–(16)を切出し画像で照合した。
- **式レビューA:** 原典と対応表だけを渡された別の担当（Claude Opus）が、REVIEW_CHECKLISTS の A1–A11 を行った。式(13)–(16)は θ = 0 で式(2)–(12)から誤植なしに導かれた。k⊥ を数値積分する独立な経路との相対差は 3.1×10⁻¹⁰ 以内だった。式の ε の運動量引数については、印刷形は ε(k∥) の値であり、原著が述べる深さ無限大の極限は ε(k_total) でだけ成り立つことが分かった（Q1）。この指摘を受けて、M2の内部検査 I1、I2、I3、I5、I7 を書き直した。
- **参照ソフトの計算:** QUEELS-XPS で Al（1000 eV、法線出射）の深さ別 K_eff を、正孔の電荷 1、0、0.5、分散0の合成入力、積分点数 250、1000、2000 で計算した（[M2_FIRST_CASE.md](M2_FIRST_CASE.md) §3）。出力は gitの管理外に置いた。比較の許容幅は、どの計算とも比べる前に §4.2 で固定した。

### 入力データについての観察（公表値に基づく。ソフト内部の処理は未確認）
