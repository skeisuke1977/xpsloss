## 1. 目的と範囲

ELF データ集 v1.0 の Si（`benchmarks/inputs/si_elfdb_v1.0.json`、\(g=1.12\) eV、3振動子、分散 0.5、絶対強度、再規格化なし）で、表面法線からの出射角 0°、正の生成深さの固定深さ断面積を計算できるようにし、検証する。式は M2-1 と同じ Simonsen ら (1997) の式(13)–(17)で、誘電応答は M1 の因果的な振動子 ELF（硬いギャップと KK による実部、`causal_oscillator_elf_v1`）を使う。[M2 の最初のケース](M2_FIRST_CASE.md)、[ROADMAP](ROADMAP.md) §5

対象外: 斜出射、深さ平均、スペクトル化、実測との比較、ギャップ下の δ 関数の寄与（§3）、§4 の受理条件を満たさない材料・損失点。

## 2. 誘電係数と実軸上の特異点

式(13)–(16)の誘電係数は、F で書くと分母が \(1-F\) だけになる。[導出: \(\epsilon=-1/F\) を代入]

| 原著の組合せ | 項 | F による形 | F = 0（ε = ∞） |
| --- | --- | --- | ---: |
| \(1/\epsilon-1\) | 13a、13b、14 | \(-S=-(1+F)\) | −1 |
| \((\epsilon-1)(\epsilon+2)/[\epsilon(\epsilon+1)]\) | 15-T1、15-T2 | \(C=(1+F)(1-2F)/(1-F)\) | 1 |
| \((\epsilon-1)/(\epsilon+1)\) | 15-T3 | \(R=(1+F)/(1-F)\) | 1 |
| \((1-\epsilon)/(1+\epsilon)\) | 16-e、16-h | \(-R\) | −1 |

- **ギャップ下（\(0<T<g\)）:** \(L=\operatorname{Im}F=0\) で F は実数。活動線があれば、E4a を固定 q で微分して \(\partial_T F=(4T/\pi)\int_g^\infty uL_0(q,u)/(u^2-T^2)^2\,du>0\)（単位 eV⁻¹）、端で \(F\to+\infty\)。静的値が負なら、F = 0（ε の極、\(T_\epsilon(q)\)）と F = 1（ε = −1、無減衰の表面モード、\(T_s(q)\)）が一つずつあり、\(T_\epsilon<T_s<g\)。係数が特異になるのは F = 1 だけで、F = 0 は F の形では正則。固定深さの経路では ε を作らない。
- **端（\(T\to g\)）:** 固定した q で \(\operatorname{Re}F\simeq[L_0(q,g)/\pi]\log(g/|T-g|)\) と発散する（M1 の D7 の節）。S と C は対数発散し、R → −1。
- **ギャップより上:** \(L>0\) なので実軸上の極はない。ただし \(\operatorname{Re}F\approx1\) で L が小さいと、細い表面共鳴になる。§4 の単調性はギャップより上には及ばず、運動量区間の内部に2つの交差や接する交差がありうる（§5 の6）。
- **分散:** \(\alpha_i>0\) では \(T_\epsilon\)、\(T_s\)、端の対数係数が q とともに変わる。\(g\) は q によらない。
- **全強度ゼロ:** \(F=-1\)、\(S=R=C=0\) で、端を含めて11出力はすべて 0。端の発散、δ、跳びの警告は出さない（M1 の D7 と同じ例外）。

## 3. 方針: 遅延極限の点値、広がりなし

**出力の定義:** 式(13)–(16)に硬いギャップの因果的な F を入れた遅延（\(T+i0\)）極限。**計算するのは、δ 関数の寄与がないことを証明できる損失点だけ**とし、ほかは理由を付けて拒否する。証明できた点では、通常の点値が遅延極限と一致する。広がり \(\eta\) は本体のモデルに入れない。2つの案がともにこれを推奨し、レビューも支持した。

### 3.1 ギャップ下の δ 関数

\(1/(x+i0)=\mathrm{PV}(1/x)-i\pi\delta(x)\) から \(R=-1+2\,\mathrm{PV}[1/(1-F)]+2\pi i\,\delta(F-1)\)。δ が入るのは R と C の虚部を使う 15-T2、15-T3、16-e、16-h である。15-T1 は実数の重みに \(\operatorname{Re}C\) を掛けるので δ は入らず、S だけの項にも入らない。[導出]

- 分散なし（全活動線で \(\alpha_i=0\)）: \(T_s\) は q によらず、寄与は損失 \(T_s\) の一点に集中する有限の重みの線になる。点の格子では表せない。
- 分散あり: 固定した T で運動量の根に δ が立つ。§4 の単調性の下では F は q について非増加なので、区間の内部に根があるのは \(F(q_+,T)<1<F(q_-,T)\) のときで、等号は端点として別扱いになる。単純根の重みは \(1/|\partial_qF\,dq/d\log k|\) を含み、各項には実部の主値も残る。運動量で積分した値は、この条件を満たす損失の帯で有限になる。帯の中の点を通常の求積で計算すると δ の部分を落とし、正孔電荷1の `total` は（§3.3 の恒等式で）誤って 0 になる。
- M2-2 の受理域は、\(F(q_-,T)<1\) を**証明した**点までとする（§4）。

### 3.2 Si では、許容するすべての点に δ がない

- **一様な上界（Codex、レビューで再確認）:** 全 \(q\ge0\)、\(0<T<g\) で、\(g<U<\min E_i\) を選ぶと
  \[
  S(q,T)\le P_0+c\log\frac{2g}{g-T},\qquad P_0=\frac{B_0}{1-(g/U)^2},\quad c=\frac{Mg}{\pi},
  \]
  \(B_0=\sum A_i/E_i^2\)、\(M=\sum A_i\Gamma_i/(E_i^2-U^2)^2\)（eV⁻¹）。分散で \(\Omega_i(q)\ge E_i\) となることを使っており、単調性は使わない。Si で \(U=3\) eV とすると \(P_0=1.1277897\)、\(c=0.0067248\)。\(g-T\ge\delta_g\) で \(S<1.3183\)、つまり **\(F<0.319\)**。F = 1 が起こりうるのは端から \(1.06\times10^{-56}\) eV 以内に限られる（上界）。
- **より強い評価（レビュー）:** §4 の単調性から最悪点は \(q=0\)、\(T=g-\delta_g\) で、差し引く除去帯域の正則な積分を有理数で下から押さえると \(F<0.138225\)。別担当の標本評価（\(1-F\ge0.86\)）と整合する。光学極限での漸近式による F = 1 の位置の推定は端から \(10^{-72.4}\) eV で、これは推定値であり上界ではない。
- \(\delta_g=1.12\times10^{-12}\) eV なので、D7 の除外幅の外では、Si のギャップ下の全点で極の不在を証明できる。0.2–99.8 eV の格子の全点の数値の成功は、実装後の試験で確かめる（§7）。
- ELF データ集の他の材料: \(q=0\)、\(T\le g-2\delta_g\) までの探索で F = 1 を挟めたのは PVC と SiO₂（端から約 \(2\times10^{-10}\) eV）。ただし PE は、除外境界のすぐ外の浮動小数点数で \(F>1\) となり、除外幅の外に表面の極がある（レビューの独立計算）。ZnSe と ZnS も、端の直下の浮動小数点数まで広げると \(F>1\) になる。

### 3.3 ギャップ下の恒等式（新しい検査 I9）

係数 S、R が実数のとき、`_term_integrands` の8項を電子群（13b、15-T1、15-T3、16-e）と正孔群（14、15-T2、16-h）に分けて足すと、\(d\log k\) あたりの密度は
\[
\frac{K'_e}{P}=S\,\frac{|1-u|^2}{D}+R\,\frac{2\operatorname{Re}u-|u|^2}{D},\qquad K'_h=-K'_e,
\]
（\(u=e^{-ka-iba}\)、\(D=b^2+k^2\)、\(b=\omega_\perp\)、\(P\) はコードの前因子）となり、**正孔電荷 \(Q_h\) の `total` は \((1-Q_h)K_e\)、正孔電荷1では点ごとに 0** になる。2つの案が独立に見つけ、レビューが整数係数の多項式として記号的に確かめた（16-e を落とすと相殺が壊れる）。13a は \(\operatorname{Im}S=0\) で消える。

- 意味: 損失のない媒質では、同時にできた中性の電子–正孔対は吸収を生まない。
- `no_hole` と `hole` は個別には 0 でない反応的な成分である（試作で Si、10 Å、0.2 eV に ±0.12 eV⁻¹ Å⁻¹）。成分をゼロに置き換えない。
- M2-2 はギャップ下の点を計算し、成分を返し、意味を警告に書く。この恒等式を検査 I9 にする（V4）。δ の寄与がある点では実係数だけへの置き換えは許されないので、I9 は §4 の証明がある点に限る。

### 3.4 端の扱い

- 活動線があれば、M1 の除外幅 \(\delta_g\)（D7）を損失格子全体に当て、計算の前に `DielectricGapEdgeError` で拒否する。評価点は動かさない。
- \(\delta_g<|T-g|\le10^{-3}g\) の点には、M1 と同じ固定 q の \(\operatorname{Re}F\) の対数項の推定を警告に記す。係数は \(q_-(T)\) で評価する（§4 の条件の下で区間内の最大）。これは誘電関数の目安であり、固定深さの成分の大きさではない。
- 正孔電荷1の `total` は、端で 0（下）から有限値（上）へ跳ぶ。試作では Si、10 Å、`k_total` で \(T=g+2\times10^{-12}\) eV の値が 0.010152、形式的な右極限（\(\operatorname{Im}S\to L_0(q,g)\)、\(\operatorname{Im}R\to0\)、\(\operatorname{Im}C\to2L_0(q,g)\)）が約 0.009361 eV⁻¹ Å⁻¹ で、両者は区別する。深さ平均やスペクトル化（M3、M4）では、\(g\) で区間を分ける必要がある。

### 3.5 選ばなかった方法

| 方法 | 選ばなかった理由 |
| --- | --- |
| (a) δ 関数を含む分布の極限を実装する | 線（分散なし）や帯（分散あり）の出力型、根の追跡、主値、帯の端の処理が要り、検証が重い。Si では極の位置が端から \(1.06\times10^{-56}\) eV 以内に制約され、格子に意味のある点がない（δ の重みを評価した値ではない）。将来の別工程にする |
| (b) 広がり \(\eta\) を入れる | 公表モデル（段差の ELF と KK の実部）を変える。\(\eta\) に出典がない。試作（Si、10 Å、`k_total`）では、ギャップ下に \(\eta\) にほぼ比例する見かけの吸収が生じ（0.4 eV で約 \(0.046\eta\) eV⁻¹ Å⁻¹ eV⁻¹）、\(\eta=0.1\) eV ではプラズモンの峰の半分を超えた。端の直上の値も \(\eta=0.01\) eV で 2.5 % 変わった |
| (c) ギャップ以下を一律に拒否する | Si ではギャップ下の点を厳密に計算でき、拒否すると 0.2–1.0 eV の点と検査 I9 を失う |

## 4. 受理条件と証明（静的符号とギャップ下の δ の不在）

推定誤差を足した計算値の比較（\(\widehat F+e<1\)）は、D3 の誤差の指標が上界でないため、証明にならない（レビューの blocker）。M2-2 は、外向きに丸めた解析的な上界だけを証明に使う。

1. **単調性の条件（受理条件）:** 全活動線が \(\Omega_i(q_{\min})>g\) かつ \((\Omega_i^2-g^2)^3>(4/\pi)\Gamma_i g\,\Omega_i^4\) を満たす。\(q_{\min}=\min_T q_-(T)\) は格子全体の最小。\(\phi(x)=(x-g^2)^3/x^2\) は \(x>g^2\) で増加するので、一度成り立てば大きい q でも成り立つ。両辺は無次元化して外向きに比較し、等号、丸め、大きな \(\Omega\) のべき乗のオーバーフローを扱う。比較は、式(17)の下端、`k_total` の法線成分、\(\Omega_i\) の丸めまで含めた**真の** \(q_{\min}\) に対して保守側で行う（最近丸めの計算値を厳密な下端とみなさない）。[導出: 静的な残存和の \(\Omega^2\) 微分の上界。レビューで確認]
   - 帰結: 静的な \(F(q,0)\) と、ギャップ下の \(F(q,T)\) は q について非増加（全活動線が無分散なら一定）。重み \(u^2/(u^2-T^2)\) が正で減少することを各 u で使う。
   - これで、現行の「\(q_{\min}\) で一度だけ判定する」静的符号の事前検査が、ギャップありでも正しくなる（Codex は、この推論がギャップありでは条件なしには成り立たないことを指摘した）。判定は M1 と同じ \(\tau_0\) の規則で、`marginal` は実際に診断した q と \(\tau_0\) に結び付けた許容幅内の診断であり、\(F\le0\) の証明とは書かない。
   - 満たさない入力は拒否する（理由 `monotonicity_condition_failed`、振動子の番号と両辺）。ELF データ集のギャップあり32材料（読み取れない PPY を除く）では、\(q=0\) で28材料が満たし、CeO₂、GaN、SiO₂、ZnO は満たさない。実行時の受理は運動学的な \(q_{\min}\) で決まり、この件数とは別である。条件は十分条件であり、満たさない材料に極があるとは限らない。
2. **ギャップ下の点の証明:** 各ギャップ下の点で、§3.2 の一様な上界を評価し、上端が**厳密に** \(S<2\)（\(F<1\)）であることを示す。
   - 上界の証明には \(g<U<\min_{A_i>0}E_i\)（活動線の**光学中心**）が要る。単調性の条件が成り立っても、この区間が空のことがある（レビューの合成例: \(g=2\)、\(E=1.9\) eV で、分散により \(\Omega(q_{\min})>g\) となる入力）。ギャップ下の点があって区間が空なら、`surface_pole_not_excluded`、`U=null`、理由の詳細を返す。ギャップより上だけの実行には U は要らない。活動線が0本なら \(S=0\) をそのまま証明とする。
   - \(B_0\) と M の和は活動線だけで取る。U の候補は、区間 \((g,\min E_i)\) の内点の等比の8点（両端を除く）とし、上界が最小のもの（同点なら小さい U）を使う。U 自体は表現可能な内点でよい。
   - 上界は \(g-T\)、分母、\(\pi\)、対数、和まで丸めの向きを管理して上から評価する（最後の1回の丸めでは先行する演算の誤差を覆えない）。使った U、上界、2 との余裕を記録する。
   - 証明できない点は拒否する（理由 `surface_pole_not_excluded`）。これは「極を検出した」という意味ではない。
   - 一般の材料で、単調性と \(q_-\) の保守的な下端を使い、残存帯域の積分を区間演算で上から囲う方法もある。M2-2 では実装せず、後の工程で検討する。
3. **証明できる範囲の明示:** M2-2 のギャップ下の受理は、一様な上界で証明できる入力に限られる。Si は D7 の外の全ギャップ下点が証明できる。端の段差が大きい入力では、極のない点も拒否される。例えばレビューの合成例（\(g=2\)、\(E=3\)、\(\Gamma=0.5\) eV、\(A=8.1\) eV²）の \(T=1.9\) eV は、\(F(0,T)=0.521\) で極はないが、どの U でも上界が 2 を超えるので拒否される。この点は「極なし・この証明では拒否」の対照に使う。

## 5. 求積の節点での実部と、段階4fの精度

**統合の判断:** 本番の実部はベクトル化した閉形式 D3、照合は数値 KK（E4a）とする（別担当の案）。Codex は E4a を先に参照経路にする案だったが、レビューは、下の試験を先に固定することを条件に D3 を本番にする判断を妥当とした。

| 方法 | 節点あたり | Si、499損失、10 Å、`k_total` の1回の見積もり |
| --- | --- | --- |
| E4a（数値 KK、既定の許容） | 約 0.08 ms | F だけで約 85–95 秒 |
| D3 スカラー | 約 0.013 ms | 約 14 秒 |
| D3 ベクトル化（試作、弱減衰の非臨界の枝のみ） | 約 1.6 µs | 試作の全体で 2.2 秒（同じ振動子でギャップなしの公開版は 1.0 秒） |

1. **実部と虚部:** \(\operatorname{Re}F\) は D3（残存帯域の部分分数）。スカラー版のすべての枝（弱減衰、臨界の両側と厳密な一致、差商の切替境界、過減衰、端の近くの中心）を移植する。配列では有効なマスクの中だけで平方根、差商、除算を行い、無効な枝の評価や配列全体の一括の失敗を避ける。S は各残存帯域の和から直接作り、大きい q で \(1+\widehat F\) として桁を失わない。\(\operatorname{Im}F\) は E1 に \(\theta(T-g)\) を掛け、ギャップ下では厳密に 0。
2. **誤差の伝播（帯域と損失の側を分ける）:** D3 の丸めの指標と、節点の座標の丸め（\(\log k\)、\(k^2\)、法線成分の加算、分散中心の丸め）を、実部と虚部に別々に入れる。\(x=\Omega_i^2\) として:
   - \(T>g\): 切断しない E4b の変化と、除去帯域 \(0<u<g\) の寄与 \(r_i\) の変化の**両方**を足す。除去帯域では \(x>g^2\) で \(|\partial_x r_i|\le2|r_i|/(x-g^2)\)。有限の座標区間には、丸めで囲った区間全体で \(m=\inf x-g^2>0\) を確立してから、例えば \(|\Delta r_i|\le4A_i\Gamma_i g^3|\Delta x|/[3\pi(T^2-g^2)m^3]\) を使う（m > 0 を確立できないときに中心値の分母を流用しない）。虚部には E1 の誤差を伝える。
   - \(T<g\): 除去帯域に主値が入るので上の式は使えない（\(r_i\) が 0 を横切っても微分は 0 でない）。正の残存帯域 \(s_i\) を使い、\(|\partial_x s_i|\le s_i/(\Gamma_i g)\)、座標の区間 \(|\Delta x|\) に対して \(|\Delta s_i|\le s_i\,\mathrm{expm1}(|\Delta x|/(\Gamma_i g))\)（基準の \(s_i\) にも上側の誤差を含める）。緩すぎる狭い線では区間を細かくする。
   - 有限差分は導出の検査に使う。D3 の指標は上界を保証しないので、Si の節点で E4a との差が指標の範囲に入ることを試験で確かめる。
3. **D3 の失敗:** D3 が悪条件を報告したら `FixedDepthConvergenceError`（`not_converged`）とし、E4a へは自動で切り替えない（M1 の方針と同じ）。段階4fの有理数による正確な再計算は、対数と逆正接を含むので使えない。要求されたら未収束で止める。試作では、Si、10 Å、`k_total`、正孔電荷1、epsabs \(10^{-14}\) で、損失 1.2、5、17、60 eV は epsrel \(10^{-11}\) で止まり \(10^{-10}\) で通った。0.4–17 eV の5点では両方とも止まった。これは損失と電荷に依存する観察であり、扱える精度の下限は実装後に測って文書と試験に書く。
4. **ギャップ下の `total` の誤差（返値と誤差の契約）:** 現行は `total` の誤差を各項の誤差の和で見積もる。ギャップ下の正孔電荷1では `total` ≈ 0 なので予算が epsabs だけになり、試作は Si の 2 Å で止まった。次のように直す。
   - 8項、`no_hole`、`hole` は従来どおり個別の予算で判定する。
   - 分岐条件は「\(g>0\)、\(0<T<g\)、§4 の証明済み、\(Q_h=1\)」に限る。ギャップより上で虚部がアンダーフローした点はこの経路に入れない。
   - この場合、`total` の被積分関数を同じ求積の節点で別に積算し（同じ節点の同じ実数 S、R、\(C=2S-R\) に対する恒等式なので、係数の誤差は §3.3 により伝わらない）、高低則の差、丸めの床、最終の集約の丸めを含めて誤差 \(e_{\rm dir}\) とする。丸めの床は、高低両則の正の重みで、C の生成、幾何因子、射影、8項の加算の**相殺前のオペランド**の大きさから積算する（`abs(total)` だけを尺度にすると床が消える）。API が成分から組み立てた値 \(K_{\rm out}\) を返すので、判定には \(e_{\rm dir}+|K_{\rm out}-K_{\rm dir}|\) を使う。初回の評価、細分、パネルの優先度、再計算の予算配分も同じ判定に揃える。
   - 誤差の欄: CSV の `quadrature_error` は、ギャップありでは11出力の推定誤差の最大（どの出力にも当てはまる上側の推定）とし、`run.json` に出力ごとの推定誤差と予算との比を別に記す。判定は11出力それぞれの予算で行う。CSV の最大を `total` の epsabs と比べる旧試験を、ギャップ下にそのまま移さない（契約が変わるため）。ギャップなしの入力の値と `quadrature_error` は変えない。
5. **成功条件（4f と同じ）:** 各損失で、8項、`no_hole`、`hole`、`total` のすべてが \(e_j\le\max(\varepsilon_{\rm abs},\varepsilon_{\rm rel}|K_j|)\) を満たす。`total` だけの合格では返さない。
6. **細い表面共鳴の扱い（ギャップより上）:** 現行の `_line_positions` は、ギャップなしの式で表面の線の位置をパネルの分点に置く。ギャップありでは、バルク線の分点を保ったうえで、振動子和全体の \(1-\operatorname{Re}F\) と \(|1-F|\) を \(z=k^2\) の区間ごとに調べる。両端の符号が同じでも内部に2交差がありうる（レビューの合成例: \(g=2\)、\(E=3\)、\(\Gamma=0.02\)、\(T=4\) eV で \(\operatorname{Re}F=-1.857,36.5,-0.993\)）ので、標本の符号変化だけでは判定しない。終了条件:
   - 各 z 区間で、§5 の2の微分の上界を使って \(\operatorname{Re}F\) の値域を囲い、1 が値域の外なら交差の候補から外す。
   - 残る区間は、\(\operatorname{Im}F\) の下限と F の変化幅から \(|1-F|\) の変化が解像できるまで分割する。接する交差の近くでは一次の線幅（\(\operatorname{Im}F/|\partial_z\operatorname{Re}F|\)）を使わない。
   - 分割の上限に達しても保守的な判定が決まらなければ `not_converged` とする。
   - Si では、D7 の外の \(T>g\) で \(1-\operatorname{Re}F\) が 0 に近づく点は、端の直上（固定 q の漸近式で端から \(10^{-77}\) eV 程度）にしかないと見込まれる。この見込みは、実装後に Si の格子の全損失と全運動量区間で上の判定を走らせて確かめ、走査の範囲と結果を記録する。
7. **ε の極（F = 0）:** 係数を F で作るので無害で、デルタ項を足さない。M1 の `sub_gap_pole_status` は ε の極の診断として q を添えて残し、表面の極（F = 1）の判定とは別の欄にする。`delta_terms` の源の \(\delta(\omega_\perp)\)（\(T=0\)）と、応答の \(\delta(F-1)\) も別に記す。

## 6. 事前検査の順序と CLI

次の段階の順に検査する。段階 1–6 の違反では、**固定深さの節点の評価（初回のバッチと単点のパネル）を一度も行わない**。M1 を再利用する静的分類と、診断用の ε の極の探索は KK の求積を行うので、この「0回」の対象には含めない。

1. （CLI）設定ファイルの読込みと、既存の出力先の拒否（既存の順）。
2. API の引数と全損失の検査（既存）。
3. 活動線があれば、全格子に D7 の除外幅（`DielectricGapEdgeError`）。
4. 各損失の \(q_\pm(T)\) の可解性（既存）。
5. 格子全体の \(q_{\min}\) で §4 の単調性の条件と静的符号。
6. 全ギャップ下点の §4 の証明。
7. 固定深さの求積。数値の失敗は `FixedDepthConvergenceError`（`not_converged`）。

- **優先順位:** 段階の間では番号の小さい段階の違反を先に報告する（後ろのバッチの D7 の違反と、前のバッチの数値の難点が混ざれば D7）。同じ段階の複数の違反は、元の添字の順に全件を報告する。段階5の静的な KK 自体が未収束になった場合は `not_converged` とし、段階6の拒否が必ず優先するとは約束しない。初期分割も収容できない `limit` は既存どおり入力エラーで、分割を尽くしても精度が足りない場合の `not_converged` と区別する。
- 新しい例外 `FixedDepthGapDomainError(ValueError)` は `xpsloss` から公開し、CLI で包括的な `ValueError` の処理の前に捕まえる。理由（`monotonicity_condition_failed`、`surface_pole_not_excluded`）ごとに必須の欄を決める: 該当する損失と添字、q の区間、振動子の番号と両辺（前者）、使った上界と U（後者、U が作れなければ `null`）、直し方。`error`、終了コード2。
- 混在した格子（後ろのバッチだけに違反がある、逆順、重複、複数の違反）でも、違反は求積の前に報告し、部分的な成功を返さない。新しい出力先は作らず、既存の出力先の中身も変えない。
- `FixedDepthResult` に既定値付きの末尾の欄（診断と警告）を加え、API が実際に行った事前検査の結果を CLI に渡す。比や最小値が定義できない場合（ギャップ下の点がない、\(\sum|K_j|=0\)）は `null` とする。manifest は NaN を書かない。

- **モデル ID:** `simonsen1997_fixed_depth_v0` を、幾何、電荷源、経路長の規格化の識別子として据え置く（式は同じで、硬いギャップは誘電応答の `causal_oscillator_elf_v1` に含まれる。Codex はギャップあり用の別 ID を提案したが、レビューは下の識別情報を条件に据え置きを支持した）。再現に必要な情報として、パッケージの版、誘電応答の ID、\(g\)、運動量の指定、広がり 0、ギャップ下の処方と証明、実部の経路（`closed_form_D3_retained_band`）、各誤差の欄の定義を `run.json` に記す。
- **`diagnostics`:** \(g\)、\(\delta_g\)、最も近い点の距離、警告帯の点と固定 q の対数項（\(q_-\) で評価）、静的符号（\(q_{\min}\)、\(\tau_0\)、値）、振動子ごとの単調性の条件の両辺、ギャップ下の各点の証明（\(U\)、上界、余裕）、ε の極の診断、`subgap_policy`、`broadening_eV: 0`、D3 の悪条件の件数、ギャップ下の恒等式の実測値、出力ごとの推定誤差と予算の比。恒等式の実測値は、受理したギャップ下の点ごとに単位電荷の \(|K_e+K_h|/\sum_j|K_{{\rm term},j}|\) を取った最大とする（対象点なし・分母 0 は `null`）。
- **`warnings`（ASCII）:** 活動線のあるギャップありの入力では常に、硬いギャップの端で Re F が対数発散し、成分が端の近くで対数的に振る舞い、正孔電荷1の `total` が端で 0 から跳ぶこと。ギャップ下の点があれば、媒質に損失がなく、正孔電荷1の `total` が 0、成分は反応項で吸収ではないこと。端の警告帯の点。
- **`applicability`:** 既存の仮定に「硬い段差のギャップ、KK で整合した実部、遅延極限、広がりなし」を加える。ギャップなしの照合範囲（1000–4000 eV、max T/E0 0.1）を Si の根拠に流用しない。ギャップありで照合した入力（Si、1000 eV、深さ、どの検査がどの出力を確かめたか）を別の欄に記録する。
- **`capabilities`:** `scope` を「ギャップなし、または §4 の受理条件を満たす硬いギャップの材料。ギャップ下の ε = −1 の寄与は対象外」に改め、`verification` にギャップありの項を加える。`unsupported_physics` から `gapped_materials` を外し、`sub_gap_surface_mode_delta_terms` と `gap_broadening` を加える。
- **既存の試験の移行:** 凍結した試験（4a、4f の数値の入力・参照・許容）と I3 のファイルは変えない。旧仕様と直接矛盾する2つの期待（ギャップのある入力を M2-2 の文言で拒否すること、`capabilities` が `gapped_materials` を挙げること）だけを、版の変更として明示して置き換える。
- **文書:** README（日本語・英語）、EQUATIONS の E5、DIELECTRIC_DESIGN（固定深さの節点では D3 が本番、E4a が照合という例外）、M1_EQUATION_MAP §4.2、VALIDATION、CHANGELOG。版は 0.2.0 を想定する。

## 10. 残る危険

1. **段差の ELF の人工物:** 硬いギャップは端の直下に ε の極、負の ε の帯、無減衰の表面モードを作る。Si では無視できるが、端の段差が大きい材料では拒否が増える。拒否は物理の判定ではなく、モデルと証明法の限界の表示である。
2. **成分の大きさ:** ギャップ下の `no_hole` と `hole` は低損失・浅い深さで大きい（試作で 2 Å、0.2 eV に ±0.60 eV⁻¹ Å⁻¹）。成分だけを図にすると誤解を招く。
3. **端の跳び:** `total` は端で跳ぶ。M3・M4 で区間を分ける必要がある。
4. **D3 の指標は上界ではない:** 狭い線、共鳴、端の近くの中心では悪条件になり、拒否が増えうる。誤った値を返さないよう、未収束で止める。ギャップ下の受理の証明には使わない（§4）。
5. **4f の判定構造への変更:** ギャップ下の `total` の誤差の扱いを変える（§5 の4）。ギャップなしの出力が変わらないことを、ELF データ集の全材料で確かめる（段階4gと同じ方法）。
6. **分散ありの `k_total` の独立経路がない:** M2-1 と同じ既知の限界。
7. **深い極限の遅い収束:** 1 eV 未満では \(10^5\) Å でも相対 \(10^{-6}\) に届かない。
8. **細い線を飛び越す危険:** ギャップより上の狭い表面構造を、求積の節点が飛び越すこと。§5 の6で分点を置き、V14 で照合する。
9. **参照ソフトとの関係:** 参照ソフトがギャップ下、端、ε = −1 をどう扱うかは分からない。外部の数値照合はない。
