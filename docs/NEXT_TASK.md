# 次の依頼に使う文面

以下をCodexまたはClaude Codeへ渡す。最初の作業範囲はM1。M2の完全実装を一括で依頼する前に、数式の対応を明らかにする。

---

このxpsloss-starterを、公開文献に基づくXPS誘電損失パッケージへ育てたいです。

まずAGENTS.md、README.md、docs/PROJECT_PLAN.md、docs/EQUATIONS.md、docs/VALIDATION.mdを読み、既存テストを実行してください。現時点で実装済みなのはELFと無限媒質のバルクDIIMFPだけです。

今回の仕事は次のとおりです。

1. Simonsenら、Phys. Rev. B 56, 1612 (1997)の原PDFを読み、式(13)-(17)の全項について、記号・単位・仮定・数値積分変数を対応表にしてください。PDF抽出文字だけに依存せず、数式画像と照合してください。必要な原PDFが取得できなければ、入手済み資料で確定できることを整理し、不足するページ・式を具体的に報告してください。
2. ELF入力から複素誘電応答をどう構成するかを設計してください。特に、ギャップのしきい値を入れた場合のクラマース-クローニッヒ整合性、有限範囲のデータからの再構成、高エネルギー側の扱いを比較してください。
3. 公式manualと2022年のデータ集のSi/Au入力を混同せず、参照計算用の固定入力セットを設計してください。第三者データを取り込む場合は出典と利用条件を記録してください。合成例を実材料と呼ばないでください。
4. 次段階M2の最初のケースを、法線出射・固定深さ・一つの参照材料に限定し、比較する数値量と合格条件を提案してください。参照ソフトの数値表が必要な場合は、実行条件と保存すべき出力を具体化してください。
5. 実装前の式レビューと実装レビューを別の担当へ依頼できるように、レビュー項目を作ってください。

未実装の表面・正孔・干渉をバルク近似で代用しないでください。CoOの実測へのフィッティングやGPU化は、この作業の完了条件には含めません。報告には、確定した式、残る不明点、入力データ、検証コマンド、次の実装単位を記載してください。
