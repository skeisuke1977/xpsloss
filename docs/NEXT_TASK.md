### M3a-2 の成立性の判定（完了、2026-11-26）

軌道ごとの長さ・自己無撞着な長さ（M3a-2）を本実装する価値があるかを、計算の前に固定した物差しで判定する。利用者がまず必要とする量は衛星の相対面積なので、比べる量は M4a の \(w_{1,W}=LA_{\rm total}\) を中心にする。

1. 判定の前に物差しを固定する。物差しは、材料とエネルギーごとの \(L\) の文献の幅と、窓の下限を変えたときの \(w_{1,W}\) と形の変化。
2. 代表の深さで、窓の面積の正しさと精度を評価する。ごく浅い深さでの固定深さの未収束（[検証記録](VALIDATION.md)の「M2-2」の残る限界）が深さの積分に及ぼす影響も、ここで調べる。
3. 2段で比べる。どちらも全成分に共通の規格化した重みを使う。
   - (a) 乗数をそろえ、深さの重みだけを、一定長から軌道ごとの長さに換える。
   - (b) 重みを固定し、乗数だけを換える。
4. 結論を次の3つから選ぶ。
   - M3a-2 を本実装する。
   - M4a に小さな乗数の選択肢を足すだけにする。この場合も、manual が自己無撞着な長さを推奨すること（Tougaard2011 p.21）を文書に書く。
   - この条件では判別できない、と記録する。

1–4 はすべて済んだ。計画は Fable と Codex が互いを見ずに批判して改め（軌道ごとの分母の読み方は規格化できないので外し、(a) を「一定長で再現できるか」と「その一定長は何で決まるか」に分け、物差しを面積と形で分けた）、利用者が物差し（論文庫の \(L\) と ±10 %）と参考の \(E_0\)（700 eV）を決めた。物差しを凍結した後に Codex が計算し、Fable が照合した。Al と Si の面積と形の4項目がすべて「小」で、利用者の同意で、軌道ごとの深さの重みは本実装しないことにした。Yubero2005 の式(7)の分母は、全軌道で共通の分母の読み方だけが計算できる。数値と限界は [ROADMAP](ROADMAP.md)の「M3a-2 の成立性の判定」にある。
