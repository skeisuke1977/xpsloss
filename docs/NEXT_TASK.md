## 段階4b　近似と適用範囲の明示

1. 固定深さの計算の `run.json` に、max(T)/E0、採用した仮定（一定速度、直線の軌道、静止した正孔、非相対論）、誘電関数の運動量の指定を記録する。
2. 数値で照合した条件とその出典を文書に示し、その範囲を外れた入力には「物理的な適用は未検証」と警告する（拒否はしない）。T/E0 = 0.9 を回帰テストの例にする。一律の境目は決めない。
3. README（日本語・英語）と VALIDATION に、`k_parallel` と `k_total` の検証の状況を分けて書く。
4. 診断名 `unstable` を、判定の中身（指定した q での静的な Re[−1/ε] の符号）に合う名前に改める。拒否の規則は変えない。

続く段階4c（検証の再現性）、4d（文書の更新）、4e（公開候補の検証）は [ROADMAP](ROADMAP.md) §5 のとおり。公開、タグ、外部への連絡、Zenodo 連携は利用者が担当する。参照ソフトの出力は公開しない。[検証記録](VALIDATION.md)・[帰属表示と配布範囲](../NOTICES.md)

## 公開後の候補　M2-2

ELF データ集 v1.0 の Si を使い、ギャップのある材料での固定深さ計算を表面法線からの出射角 0° に限定して検証する。着手の前に、ギャップ端と実軸上の極の扱い（広がりの導入を含む）を決めて文書にする。着手条件は M2-1 の公表モデルの内部検証完了である。使用する絶対強度、正の生成深さ、損失格子、許容幅を計算前に記録する。M1 のクラマース–クローニッヒ実部を用いてギャップ端と極を診断し、格子の収束および独立経路との一致を確認する。[ケースの条件](M2_FIRST_CASE.md)・[固定入力の来歴](BENCHMARK_INPUTS.md)・[誘電応答の設計](DIELECTRIC_DESIGN.md)
