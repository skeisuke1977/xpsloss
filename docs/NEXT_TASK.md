# 次の作業

v0.1.0 の対象は M0、M1、M2-1 である。次の公開作業は段階3の候補検証、公開後の科学計算の第一候補は M2-2 とする。[決定と担当範囲](ROADMAP.md)

## 段階3　公開候補の検証

1. ローカルの公開用複製に D4・D7 を反映する。全履歴から個人メールとマニュアル由来のSi数値を除き、履歴中の式・入力・合否基準の事前登録が結果より前にあることを確認する。文書のコミット参照を更新し、入力・予測コード・データ原本の SHA-256 を維持する。
2. 履歴と配布対象を再点検した候補を、利用者が GitHub の非公開リポジトリへ push する。同じコミットで、Linux の Python 3.10 と最低依存版、Windows の Python 3.12、macOS の1版の CI を実行する。OS、Python、NumPy、SciPy の版と全テストの結果を記録する。
3. 原本ハッシュ、固定深さの独立経路 I3、合成入力による比較スクリプトの合格・不合格の JSON 判定を確認する。別ジョブで wheel を導入し、ソースツリー外で同じ版の合成例のバルク・固定深さ計算を実行する。PyPI 配布を検討する場合は、展開した sdist 単独でも全テストを通す。

公開タグ、外部への連絡、Zenodo 連携は利用者が担当する。参照ソフトの出力は公開しない。[検証記録](VALIDATION.md)・[帰属表示と配布範囲](../NOTICES.md)

## 公開後の候補　M2-2

ELF データ集 v1.0 の Si を使い、ギャップのある材料での固定深さ計算を表面法線からの出射角 0° に限定して検証する。着手条件は M2-1 の公表モデルの内部検証完了である。使用する絶対強度、正の生成深さ、損失格子、許容幅を計算前に記録する。M1 のクラマース–クローニッヒ実部を用いてギャップ端と極を診断し、格子の収束および独立経路との一致を確認する。[ケースの条件](M2_FIRST_CASE.md)・[固定入力の来歴](BENCHMARK_INPUTS.md)・[誘電応答の設計](DIELECTRIC_DESIGN.md)
