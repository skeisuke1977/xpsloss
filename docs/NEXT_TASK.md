# 次の作業

v0.1.0 の対象は M0、M1、M2-1 である。段階3（公開用の履歴と非公開リポジトリでの CI）は完了した。利用者のレビュー（2026-11-20）で、非常に狭い共鳴を含む入力で数値積分が誤った値を成功として返す欠陥が見つかった。公開の前に段階4（4a–4e）を行う。リポジトリは、利用者が決めるまで非公開のままにする。[決定と担当範囲](ROADMAP.md)

## 段階4a　数値の頑健性（公開を止める）

対象は `bulk_diimfp`、誘電応答（ギャップのない振動子の解析式、ギャップのある KK、表形式の KK）、光学和則の補助関数、`xps_fixed_depth` の各項と補助の閉形式である。

1. 修正の前に、回帰テストの入力、独立に計算した参照値、量ごとの許容誤差を固定する。対象の反例は [ROADMAP](ROADMAP.md) §3.3 R1・R1′ と §5 段階4a に挙げた。
2. 共鳴の中心と線幅に応じて積分区間を細分する。線幅だけの一律のしきい値に頼らない。
3. 有効だが数値的に解像できない入力は、API では未収束の例外、CLI では0以外の終了コードと `not_converged` で失敗させ、成功の実行記録を書かない。
4. 既存の75件と新しい回帰テストが合格し、別担当のレビューで blocker がないことを確かめる。

続く段階4b（近似と適用範囲の明示）、4c（検証の再現性）、4d（文書の更新）、4e（公開候補の検証）は [ROADMAP](ROADMAP.md) §5 のとおり。公開、タグ、外部への連絡、Zenodo 連携は利用者が担当する。参照ソフトの出力は公開しない。[検証記録](VALIDATION.md)・[帰属表示と配布範囲](../NOTICES.md)

## 公開後の候補　M2-2
