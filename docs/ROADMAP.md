## 1. 現状（2026-11-20、利用者のレビューの時点）

- **QUEELS-XPS v2.1 との比較:**
  - データ集のAl（分散あり）では、事前に固定した基準で不合格だった。
  - 事前登録試験で、試験した条件の参照ソフトの出力が、実部の分子に分散前のエネルギーを使う候補の処方と一致することを確かめた（[QUEELS_DISPERSION_TEST.md](QUEELS_DISPERSION_TEST.md)）。
  - 本パッケージは公表された式だけを実装する（利用者の決定）。

    （2026-11-20 追記）追試の分母は同じ深さ・判定区間の参照 `total` の最大値である。本体のAPI・CLIは公表式を使う。段階4cで追試専用の候補コードを `benchmarks/queels_prereg/` に収録した。

## 2. 最初の公開版 v0.1.0 の範囲（推奨）

**読者:** 公表された誘電応答モデルを追試したい研究者・開発者。

**含めるもの（GitHub のタグの内容）:**
- M0、M1、M2-1 の Python API と CLI、テスト
- 固定入力と来歴、検証記録、式の対応表
- 比較スクリプト。M2_FIRST_CASE §4.2 の Al の比較に使ったもので、利用者の手元の参照ソフトの出力を読む。参照ソフトの出力は含まない
- 事前登録の比較の予測コード（派生版）、凍結した予測、評価用のスクリプト（段階4c）
- 原著の図3・5・8の再現コード（段階4c）

通常のテストには、参照ソフトも非公開の出力も要らない。wheel は本体とライセンス資料を収録する。例、固定入力、技術文書、テスト、検証用スクリプトは同じ版のソース配布物に収録する（§3.1 #13、VALIDATION の段階4c）。

**主張すること:**

> 表面法線からの出射角0°、正の生成深さ、ギャップのない材料について、Simonsen ら（1997）の式(13)–(17)に基づく固定深さの有効断面積を実装した。誘電関数の運動量の引数は、利用者が指定する。`k_parallel` は閉形式の導出で用いた近似に対応し、`k_total` は法線出射で、分散を含むバルク極限を再現する。式と実装は、実装担当とは別のエージェントが検査した。原著の図3・5・8は、別担当が原著の式(20)を使った独立なコードで再現を試みた。比較点ごとの結果（読取り誤差の範囲に入った点、超えた点、幅の仮定に依存した点）は検証資料に記す。

各検証が何を確かめたかを、運動量の指定ごとに分けて書く。
- `k_parallel`: 独立な数値経路 I3 で照合した（分散なしと、分散あり）。
- `k_total`: 13a の恒等式と深い極限、同じ閉形式の別の実装との照合で確かめた。分散のある入力について、有限深さの全項を元の電荷・電位の式から独立に検証したものはない（分散のない入力では両指定が一致するので、I3 が両方を確かめている）。

**主張しないこと:**
- QUEELS-XPS との同等性。試験した分散のある入力では一致しなかったことを明記する。
- 実材料・実測スペクトルに対する妥当性。
- 深さ平均やスペクトルの結果、斜出射。
- 第三者による査読。レビューは、エージェントと利用者（開発者本人）によるものである。
- 一定速度の近似が成り立たない条件（損失が初期運動エネルギーに比べて小さくない条件）での物理的な妥当性。計算できる範囲と、検証した範囲を分けて示す（§5 段階4b）。

**公開しないもの:**
- QUEELS-XPS の出力と数値表
- 論文の PDF とページ画像、manual の本文と図
- 会話ログ、`work/`、`.worktrees/`、作業者固有のパス
- 著者との未公開のやり取り

**M2-2 を初版に含めない理由:** 初版は、検証が済んだ範囲だけで出す。M2-2 は4–8人日の作業を見込み、初版の後の優先候補とする。

  - 有効だが数値的に解像できない入力は、API では未収束の例外、CLI では0以外の終了コードと `not_converged` で失敗し、成功の実行記録を書かない。これをテストで確かめる。不正な入力は `error` とする。

**段階4b 近似と適用範囲の明示:**
- 固定深さの計算の `run.json` に次を記録する: 損失の最大値と初期運動エネルギーの比（max(T)/E0）、採用した仮定（一定速度、直線の軌道、静止した正孔、非相対論）、誘電関数の運動量の指定。
- 数値で照合した条件とその出典を、文書に示す。入力がその範囲を外れたときは、「物理的な適用は未検証」と警告する（拒否はしない）。T/E0 = 0.9 を回帰テストの例にする。範囲の内側であることを、物理的な妥当性の保証としては扱わない。一定速度の近似が成り立つ境目を、一律の値で決めることはしない。
- 既存の定義域の規則（0 < T < E0 など）と、未収束による拒否の規則は変えない。
- README（日本語・英語）と VALIDATION に、`k_parallel` と `k_total` の検証の状況を分けて書く（§2）。

## 6. QUEELS-XPS との比較を公表するときの書き方

元の不合格、追試、採用したモデルの順に書く。公表文の例:

> 分散のあるデータ集のAlを、1000 eV、法線出射、深さ 9.967 Å で比較した。1.0–99.8 eV で事前に定めた点ごと・面積の基準に対し、運動量の引数の両方の指定が不合格だった。`total` の最大の絶対差は、同じ範囲の参照 `total` の最大値に対し、`k_total` で 6.6 %、`k_parallel` で 7.5 % だった。
>
> この結果から立てた仮説と判定基準を、新しい合成入力3件の計算の前にローカルの git に記録した。追試は、低損失での参照成分の収束を考え、5.0–99.8 eV、各計算で 10 Å に最も近い深さを判定の対象とした。3件すべてで、`k_total` と、分散前のエネルギーを実部の分子に用いた候補の式は、全3成分の最大の絶対差が参照 `total` の最大値の 0.3 % 以内だった。公表された式では、各入力の少なくとも1成分がこの基準を超えた。
>
> 本パッケージは、Yubero ら（1996）が公表した式(32)を採用する。試験で照合した対象は v2.1 の数値出力であり、内部の実装と、実測に対する精度は確かめていない。

あわせて、次の点も書く。
- 残る約 10⁻³ の差の原因は未確定である。
- 参照ソフトの出力は公開しない。
