## 1. 現状（2026-11-20、main `5be3e0a` 時点）

- **実装済み（main）:**
  - M0: 振動子ELF、無限媒質のバルクDIIMFP
  - M1: 因果的な複素誘電応答（ギャップのある材料を含む）、文献由来の固定入力と来歴、式の対応表
  - M2-1: ギャップのない材料、法線出射、固定深さでの表面・正孔・真空中・干渉の項。Simonsen ら 1997 の公表式
- **自動テスト:** 74件。
  - Windows 11、Python 3.12.10、NumPy 2.5.5、SciPy 1.18.1 で合格。
  - Codex の点検では、Windows の Python 3.11.14 で、依存の最低版 NumPy 1.24.0・SciPy 1.10.0 を使って合格した。
  - Python の宣言下限 3.10、Linux（M0 以外）、macOS は未確認。
- **QUEELS-XPS v2.1 との比較:**
  - データ集のAl（分散あり）では、事前に固定した基準で不合格だった。
  - 事前登録試験で、試験した条件の参照ソフトの出力が、実部の分子に分散前のエネルギーを使う候補の処方と一致することを確かめた（[QUEELS_DISPERSION_TEST.md](QUEELS_DISPERSION_TEST.md)）。
  - 本パッケージは公表された式だけを実装する（利用者の決定）。
- **未実装:** M2-2（ギャップのある材料での固定深さ XPS 計算）、斜出射（Q3、Q15）、M3（深さ平均）、M4（スペクトル）、M5（CoO／Quanty）。

## 2. 最初の公開版 v0.1.0 の範囲（推奨）

**読者:** 公表された誘電応答モデルを追試したい研究者・開発者。

**含めるもの（GitHub のタグの内容）:**
- M0、M1、M2-1 の Python API と CLI、テスト
- 固定入力と来歴、検証記録、式の対応表
- 比較スクリプト。M2_FIRST_CASE §4.2 の Al の比較に使ったもので、利用者の手元の参照ソフトの出力を読む。参照ソフトの出力は含まない

通常のテストには、参照ソフトも非公開の出力も要らない。PyPI に出す場合の wheel と sdist の中身は §3 #13 を参照。

**主張すること:**

> 表面法線からの出射角0°、正の生成深さ、ギャップのない材料について、Simonsen ら（1997）の式(13)–(17)に基づく固定深さの有効断面積を実装した。誘電関数の運動量の引数は、利用者が指定する。`k_parallel` は閉形式の導出で用いた近似に対応し、`k_total` は法線出射で、分散を含むバルク極限を再現する。式と実装は、実装担当とは別のエージェントが検査した。原著の図3・5・8は、別担当が原著の式(20)を使った独立なコードで、図の読取り誤差の範囲で再現した。

**主張しないこと:**
- QUEELS-XPS との同等性。試験した分散のある入力では一致しなかったことを明記する。
- 実材料・実測スペクトルに対する妥当性。
- 深さ平均やスペクトルの結果、斜出射。
- 人による査読。レビューはエージェントによるものである。

**公開しないもの:**
- QUEELS-XPS の出力と数値表
- 論文の PDF とページ画像、manual の本文と図
- 会話ログ、`work/`、`.worktrees/`、作業者固有のパス
- 著者との未公開のやり取り

**M2-2 を初版に含めない理由:** 初版は、検証が済んだ範囲だけで出す。M2-2 は4–8人日の作業を見込み、初版の後の優先候補とする。

## 6. QUEELS-XPS との比較を公表するときの書き方

元の不合格、追試、採用したモデルの順に書く。公表文の例:

> 分散のあるデータ集のAlを、1000 eV、法線出射、深さ 9.967 Å で比較した。1.0–99.8 eV で事前に定めた点ごと・面積の基準に対し、運動量の引数の両方の指定が不合格だった。`total` の最大の絶対差は、同じ範囲の参照 `total` の最大値に対し、`k_total` で 6.6 %、`k_parallel` で 7.5 % だった。
>
> この結果から立てた仮説と判定基準を、新しい合成入力3件の計算の前にローカルの git に記録した。追試は、低損失での参照成分の収束を考え、5.0–99.8 eV、各計算で 10 Å に最も近い深さを判定の対象とした。3件すべてで、`k_total` と、分散前のエネルギーを実部の分子に用いた候補の式は、全3成分の最大の絶対差が参照 `total` の最大値の 0.3 % 以内だった。公表された式では、各入力の少なくとも1成分がこの基準を超えた。
>
> 本パッケージは、Yubero ら（1996）が公表した式(32)を採用する。試験で照合した対象は v2.1 の数値出力であり、内部の実装と、実測に対する精度は確かめていない。

あわせて、次の点も書く。
- 残る約 10⁻³ の差の原因は未確定である。
- 参照ソフトの出力は公開しない。
