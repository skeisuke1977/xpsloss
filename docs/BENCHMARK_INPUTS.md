## バルク実行設定の範囲

`model.py` はギャップと各振動子の中心、絶対強度、減衰、分散を使う。入力記録には `ac`、`bc`、屈折率 `n` も保存する。データ集ヘッダーによれば `ac = 0.001` と `bc = -2` の組は内殻励起補正パラメータの欠測を示す。この補正と屈折率は現行バルク計算に入らない。原本で屈折率の欄に `999` がある材料も値をそのまま保存する。原本のヘッダーには `999` の明示的な定義がない。

データ集のファイルは材料パラメータを収録し、電子エネルギー、角度、深さ、損失格子や下限、規格化手順を指定していない。3件の `*.bulk.json` には、このリポジトリの動作確認用として初期運動エネルギー 1000 eV、損失格子 1–100 eV（1 eV刻み）を設定した。振動子は実材料由来の値を用いた。計算は均質な無限媒質のDIIMFPに限り、QUEELS-XPSとの比較には使わない。[検証コマンド](../benchmarks/README.md)

Al 2s角度依存の Yubero2005 は p.045414-3、図1直後で振動子を $E_i=15.0$ eV、$A_i=225$ eV²、$\gamma_i=1.5$ eV、$\alpha_i=1$、$E_g=0$ eV と指定する。データ集のAlは 15.6 eV、243.3598 eV²、1.5 eV、1、0 eV。中心と強度が異なるため、2005年の角度依存を検証する際は同論文の値が必要になる。[Yubero2005](https://doi.org/10.1103/PhysRevB.71.045414)

## Siの強度比と光学和則

（公開用の履歴を作成した際、QUEELS-XPS v2.1 マニュアル由来の数値を含む記述を、公開版のこの節に置き換えた。2026-11-20）

2022年のデータ集にあるSiの絶対強度と、QUEELS-XPS v2.1 マニュアルにある相対強度は、全振動子で共通の倍率だけ異なる。幅・積分範囲・損失格子を変えた光学和則の試算では、この倍率を説明できなかった。倍率の由来は未解決で、マニュアル由来の記録は配布対象外である。

光学極限で $T=\hbar\omega$（eV）と置くと、和則の左辺は次の無次元量になる。$E_i$ と $\gamma_i$ の単位は eV、$A_i$ は eV² である。[Tougaard ら（2022）式(9)–(11)](https://doi.org/10.1002/sia.7095)

```text
S(Eg) = (2/π) Σ_i ∫[Eg,∞) A_i γ_i / [(E_i² − T²)² + (γ_i T)²] dT
R = 1 − 1/n²
```

データ集のSi絶対強度では、ギャップなしで $S_0=0.970600888$、原本のギャップを入れて $S(E_g)=0.958316637$ となる。どちらもデータ集の屈折率から求めた右辺 $R=0.922839506$ を上回る。以下の表とコードは、同じ計算を原本の全材料について示す。

### 再計算

リポジトリのルートから `PYTHONPATH=src` でPythonを起動し、以下を実行する。絶対・相対許容誤差を $10^{-10}$ から $10^{-12}$ に変えた場合の左辺の最大変化は約 $1.9\times 10^{-15}$ だった。

```python
from hashlib import sha256
from math import inf, pi
from pathlib import Path

from scipy.integrate import quad

from xpsloss.elfsource import parse_elf


def moment(oscillators, gap, upper=inf, width_factor=1, tolerance=1e-12):
    total = 0.0
    for energy, strength, width in oscillators:
        gamma = width_factor * width

        def kernel(loss):
            return 2 * strength * gamma / (
                pi * ((energy**2 - loss**2)**2 + (gamma * loss)**2)
            )

        bounds = [gap, energy, upper] if gap < energy < upper else [gap, upper]
        for lo, hi in zip(bounds, bounds[1:]):
            total += quad(kernel, lo, hi, epsabs=tolerance, epsrel=tolerance)[0]
    return total


path = Path("benchmarks/sources/zenodo6024064_v1.0/ELF.txt")
raw = path.read_bytes()
assert sha256(raw).hexdigest() == (
    "1a59cc61a562f53e3bda0eec0c29df3d0a84b601fdc0aecee454be62db738f48"
)
lines = raw.splitlines(keepends=True)
assert lines[414].strip() == b"PPY - polypyrrole [20]"
assert lines[415].split() == [b"0.001", b"-2"]
lines.insert(415, b"@\r\n")
materials = parse_elf(b"".join(lines)).materials

for entry in materials:
    oscillators = [
        (float(o.energy_eV), float(o.strength_eV2), float(o.width_eV))
        for o in entry.oscillators
    ]
    n = float(entry.refractive_index)
    lhs = moment(oscillators, float(entry.gap_eV))
    rhs = 1.0 if n == 999 else 1 - n**-2
    print(entry.name, f"{lhs:.6f} {rhs:.6f} {lhs - rhs:+.6f}")
```
