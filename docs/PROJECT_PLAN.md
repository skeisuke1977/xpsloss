# 共同開発計画

作成日: 2026-11-19。以下の工程は設計案であり、未実装機能の一覧を含む。

## 1. 到達目標

均質・等方・半無限媒質を出発点に、公開されたSimonsen-Yubero-Tougaardの誘電応答モデルに基づくXPS有効非弾性散乱を再現する。その後、Quanty等で求めた一次励起スペクトルを測定スペクトルへ対応させる。

最初の対象は、一材料・平坦表面・指定した電子運動エネルギー・指定出射角とする。REELS逆解析、薄膜多層系、異方性、粒子形状、一般の弾性散乱輸送、GPU化、GUIは後続課題にする。

実装言語はPython。数値基盤にNumPy/SciPyを使い、独立したコアAPIとCLIを持たせる。独自CLIを呼べれば、エージェント専用のMCPサーバーは初期要件にしなくてよい。

## 2. 科学的な役割

QUEELS-XPSは、材料の誘電応答を用いて、移動電子・静止正孔・表面境界に由来する損失を計算する。多重項やスピン軌道分裂を量子化学的に求める機能とは役割が異なる。[R1, R3]

将来の流れは、材料の誘電応答と測定条件から損失作用を求め、一次励起スペクトル・寿命幅・装置応答と組み合わせ、実測データに照合する構成にする。エネルギー依存性が大きい範囲では、全スペクトルを一つの固定カーネルで処理できるとは限らない。

CuOの電荷移動多重項計算との比較、NiOの局所・非局所遮蔽の解析に先例がある。[R5 §3.4, R7] CoOへの移植は有望だが、同じ入力・分離仮定が妥当とは未検証である。

## 4. 本体で特に注意する定義

1. **深さと経路長**: 法線からの角度をtheta、深さをzとすれば、直線軌道の固体内経路長はz/cos(theta)。真空中の損失も含めた有効断面積を、この固体内経路長で割る。
2. **成分の符号**: 正孔を取り除いた計算との差を正孔由来成分とすると、干渉を含むため負値があり得る。全量の検査と成分の検査を分ける。
3. **深さ重み**: 単一散乱の選択が入るため、単なる指数減衰だけの平均とは限らない。外部一定lambdaと自己無撞着モードは同じコードに混ぜず定義する。
4. **多重散乱**: 全有効断面積を何回も畳み込む方法には近似がある。近似モデルID、次数打ち切り、正孔項をどう扱ったかを保存する。
5. **低損失端**: 下限値の違いが積分値や規格化に影響する。下限を隠れた定数にしない。

これらは元モデルの定義・制限に基づく。[R2 pp.1613-1615, R3 pp.20-22,31] 原著は、深さ無限大で厳密なバルク式に一致するのを法線出射に限って述べている。斜出射では積分範囲近似の影響があるため、理想的な極限テストと原実装の互換テストを区別する。

## 5. 誘電応答とCoOの入力

ELFは物性を与える入力であり、元素名を入れれば自動で決まるものではない。光学極限q=0だけが得られる場合には有限qへの拡張がモデル仮定になる。

公式ELF集にはSi/Auを含む多数の例がある。[R8] 調査したELF.txtにはCoO、In2O3、LaCoO3を確認できなかった。実材料への適用では、REELS/EELS/光学測定または適切な理論計算から妥当な応答を用意し、その誤差を評価する。測定法が違うデータを使うときは、温度、相、価数、表面状態、エネルギー範囲、運動量条件を確認する。

NiOやCuOは開発検証には有用だが、CoOの代替物性と断定しない。CoOの2p主線だけを使ってELF、Quantyの浴、多重項パラメータ、幅、背景を一斉に最適化すると、異なる物理が互いの誤差を吸収し得る。このため、まず独立データで損失の側を拘束し、角度や光子エネルギーの異なる測定を共有パラメータで比較する設計を推奨する。

## 6. Quantyとの接続

最初に次の台帳を作る。

| 項目 | 記録内容 |
| --- | --- |
| 一次励起のモデル | 局所配置、電荷移動、非局所遮蔽、浴、終状態の範囲 |
| 誘電損失 | 集団励起、バンド間遷移、表面・正孔効果のモデルと入力 |
| 線幅 | 寿命幅がQuanty出力に含まれるか、装置幅はどこでかけるか |
| エネルギー軸 | 束縛/運動、eV、基準位置、仕事関数・光子エネルギーの扱い |
| 適用した処理 | 既存の背景差引き、規格化、スムージング、畳み込み |

同じ『内因性』という呼称だけで、全部重複とも完全に独立とも判断しない。局所・非局所終状態と誘電損失の対応をモデルごとに点検する。CuO/NiOの先例は接続の可能性を示すが、特定のCoOモデルにおける二重計上がないことを保証するものではない。[R5,R7]

## 7. 検証用の参照出力

元ソフトは数値比較の対象として使うと有用。Windows上での入力と出力をセットで保存する。必要なのは、指定された入力条件での数値表、画面の条件記録、ソフトの版であり、元DLLを新ソフトに取り込む必要はない。

参照例ごとに以下を固定する。

- 材料入力の版と出典。manualと後年データ集の値を混ぜない。
- 電子の運動エネルギー、法線基準の角度、深さ、経路長。
- 損失エネルギー範囲・刻み、積分精度、低損失下限。
- 全量・正孔なし・正孔差分の定義。
- 深さ平均の方法、lambdaの与え方、弾性散乱に関する選択。
- 出力単位、面積・ピーク等の規格化方法。

ピーク位置だけの一致、スクリーンショットの見た目だけの一致は、十分な検証とはしない。画像しかない場合は読み取り誤差を明示する。

## 8. エージェントの分担

一方が式を実装し、もう一方が独立に導出・単位・極限・入力データを監査する。両者の同意だけを科学的な正しさの根拠にしない。解析基準、文献、元ソフトの出力で照合する。

先生が担う判断は、物理の適用範囲と実験との対応。日常的な入出力、格子走査、テスト実行、差分表、作図はCLIで自動化する。計算範囲を小さく区切り、各段階で再現可能な成果を残す。
