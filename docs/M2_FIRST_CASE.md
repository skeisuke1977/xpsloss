## 1. ケースの定義

| 項目 | M2-1（最初に実装・比較） | M2-2（次に追加） |
| --- | --- | --- |
| 材料入力 | `benchmarks/inputs/al_elfdb_v1.0.json`（ELFデータ集 v1.0 のAl。15.6 eV、243.3598 eV²、幅1.5 eV、分散1、ギャップ0） | `si_queels_manual_v2.1.json` または `si_elfdb_v1.0.json`。どちらを使うかは比較の前に決め、混ぜない |
| 電子の運動エネルギー E0 | 1000 eV | 1000 eV |
| 出射角 θ（表面法線から） | 0°のみ | 0°のみ |
| 生成深さ a | 参照ソフトの深さ格子のうち10 Åに最も近いもの（§3。実行7で 9.967149 Å）。内部試験では 2, 10, 50, 200 Å と 10³–10⁵ Å | 同左 |
| 損失格子 | 0.2–99.8 eV、0.2 eV刻み。合否の判定は 1.0–99.8 eV で行う | 同左 |
| 正孔の電荷 | +1（素電荷単位）と 0。線形性の検査に 0.5 | 同左 |

**Alを先にする理由**

- ギャップがない。このため −1/ε は解析式で求まり、M1で扱ったKKのギャップ端の発散やギャップ下の極が比較に入らない。表面・正孔の幾何だけを先に確かめられる。
- 単一振動子で Σ A/E² = 1 を満たす金属入力である。参照ソフトが強度を和則で規格化しても、n = 999 では強度の変化が 10⁻⁶ 程度にとどまる。Siで未解決の強度の倍率（[BENCHMARK_INPUTS.md](BENCHMARK_INPUTS.md)）が結果に入らない。参照ソフトの画面でも KK-sum は 1 と表示された。
- 1997年原著の図2–5はAlで計算されている。図3の条件は E0 = 1000 eV、θ = 0°、a = 2, 10, 50 Å である。誘電関数の形は原著式(20)と異なるため数値の比較には使えないが、形の目視確認ができる。

θ > 0 は除外する。原著は、深さ無限大で式(1)に一致するのは法線出射だけと述べ、斜出射での不一致を k⊥ の積分範囲の近似によるものかもしれないとしている（p. 1615左）。式(17)の根の選び方も未確定である（Q3）。さらに式レビューAは、印刷された閉形式が方位角を0に置いた形であり、方位角を積分すれば θ によらず式(1)に一致することを示した（Q15）。θ > 0 はこの点を検討してから扱う。

M2-2（Si）は、M2-1が合格した後に追加する。（2026-11-20 追記: M2-1 は参照ソフトとの比較で不合格だった。その原因は参照ソフト側の実部の処方と特定された（§4.4）。そこで、公表モデルの内部検証が済んだことを M2-2 の開始条件とする。旧基準と不合格の記録はそのまま残す。）ギャップを含むので、M1のKKによる実部、ギャップ端の除外、極の診断をそのまま使う。Tougaard & Yubero 2004（R12）の図3と manual p. 12 の図3は、同じ条件（Si、1000 eV、法線出射、x0 = 10 Å）を QUEELS-XPS で計算したものである。図からの読取りは目視確認にだけ使う。

## 2. 比べる量

参照ソフトの出力と原著の用語は一致していない。そこで本パッケージでは、次の名前と定義を使う。

| 本パッケージの名前 | 定義 | 参照ソフトの対応ファイル | 符号 |
| --- | --- | --- | --- |
| `total` | 正孔ありの K_eff = K_M1 + K_M2 + K_M3 + K_V（原著 p. 1614）。単位は eV⁻¹ Å⁻¹ で、固体内の経路長 x = a/cos θ 当たり | `K_XPS_T_*.m`（q-hole = 1 の実行） | 正（manual p. 13。参照出力でも正） |
| `no_hole` | 正孔の電荷を0にした K_eff。原著の「electron contribution」（p. 1616右） | `K_XPS_e_*.m` | 負になり得る（参照出力で、浅い深さと30 eV以上で負） |
| `hole` | 電荷1の正孔による `total − no_hole`。原著の「hole contribution」。干渉を含む | `K_XPS_h_*.m`（q-hole の設定によらず電荷1の値。§3） | 負になり得る（原著 p. 1617右、manual p. 13） |
| 項別 | 13a、13b、14、15-T1/T2/T3、16-e/h（[M1_EQUATION_MAP.md](M1_EQUATION_MAP.md) §4.2） | 出力なし | 内部診断用 |

原著 p. 1615左の K_eff = K_intr/x + K_extr は、経路長への依存で分けた別の分解である。混同を避けるため、本パッケージの出力では intrinsic/extrinsic という語を使わない。

**正孔の電荷についての線形性:** 式(2)は K_eff を誘導電位の一次式で与え、誘導電位は正孔の電荷の一次式である。このため K(q) = no_hole + q·hole が厳密に成り立つ（式レビューA6で確認）。参照ソフトでも、同じ実行の中で T = e + q·h が単精度の範囲で成り立った（§3）。

### 4.2 参照ソフトとの比較（M2-1）— 許容幅（固定）

この節は、本パッケージの M2 実装がなく、どの計算の値も参照ファイルと比べていない時点で書いた。参照ファイルについて見たのは、書式、表示桁、参照ファイル内の整合、n_integr による変化だけである。比較の後には変えない。変更が必要になった場合は、変更前の文と理由を残し、変更後の結果を別に報告する。

- **参照:** 実行7（`K_XPS_{T,e,h}_Al_1000_0_q1_n2000.m`、n_integr 2000、q-hole 1）の第8列。深さ 9.967149 Å。本パッケージはこの深さで計算する。
- **比較点:** 1.0–99.8 eV の0.2 eV刻み（495点）。
- **参照の数値誤差の目安:** 成分 C（`total`、`no_hole`、`hole`）ごとに u_C(E) = |K_C,n2000(E) − K_C,n1000(E)|。実行6と7の同じ列の差で、両者の深さの差は 1.4×10⁻⁵ Å である。
- **合格（各成分）:** すべての比較点で |K_本,C(E) − K_参照,C(E)| ≤ 3·u_C(E) + 10⁻³·max_E K_参照,total(E)。
- **合格（面積）:** ∫ K dħω（1.0–99.8 eV、台形則）について、|A_本,C − A_参照,C| ≤ 3·|A_C,n2000 − A_C,n1000| + 10⁻³·A_参照,total。
- **ε の運動量引数:** 本パッケージは `k_parallel` と `k_total` の両方で計算する。式レビューAによれば両者の差は `total` で最大約5%で、上の許容幅より大きい。一方だけが合格すれば、それを参照ソフトの選択と判断する。両方が合格すれば判別できなかったと記録する。両方が不合格なら、下の順で原因を調べる。

`no_hole` と `hole` は 1 eV 付近で u が大きく（max T の数 %）、この領域の検査は弱い。この限界はそのまま報告する。

参照ファイル自体の整合は、比較の前に確かめた（§3）。同じ実行の中で T = e + q·h（q = 1、0、0.5）が成り立ち、正孔の電荷について線形である。

許容幅を超えた場合は、合格とはせず、次の順で原因を切り分けて記録する。

1. 深さの値（ファイルの値を使ったか）
2. ε の運動量引数（Q1）
3. 速度を非相対論で扱ったかどうか。原著は E0 = ½mv² である。1000 eV では、相対論の補正で v² が約 0.29 % 変わる
4. 損失の格子の読み方（0.2·i）と、低損失側の積分
5. 参照ソフトの n_integr への依存（必要なら n_integr を上げた実行を追加する）

ピークの位置だけの一致や、図の見た目だけの一致は、合格の根拠にしない。分散0の実行（実行4、5）は n_integr 250 だけなので、数値の合否には使わず、診断に使う。

### 4.3 原著の図との目視確認（合否には使わない）

原著図3（Al、1000 eV、θ = 0°、a = 2, 10, 50 Å と式(1)）について、次の傾向を確かめる。

- 浅いほど全体が大きくなる。
- 表面プラズモン（約11 eV）が、浅いほど相対的に強くなる。

### 4.4 結果（2026-11-20）

- **内部検査:**
  - I1、I2、I4、I6、I7、I8 は合格した。
  - I3（別担当の独立な数値経路）も合格した。
  - 自動テストは全74件が合格した（[VALIDATION.md](VALIDATION.md)）。
- **原著の図:** 別担当のコードで、原著の誘電関数（式(20)）を使い、図3・5・8を読取り誤差の範囲で再現した。

  - 9.967 Å で、`total` は max の 6.6 %（k_total）と 7.5 %（k_parallel）ずれた。

  - 結果のファイルは `work/comparisons/m2_1_al_1000_0.json`（gitの管理外）。
- **原因の切り分け（§4.2 の手順2、ε の運動量引数から）:**
  - 分散0の合成入力では、全成分・全深さで 0.1–0.4 % 一致した。
  - 深さ182 Å のバルク部分は、`k_total` で約0.1 % 一致した。

- **判断（利用者、2026-11-20）:**
  - 本パッケージは公表された式（KK関係を満たす Yubero ら 1996 の式(32)）だけを実装する。参照ソフトの処方を再現する選択肢は設けない。
  - 分散のある ELF では、QUEELS-XPS v2.1 の出力と一致しないことを、README と VALIDATION に明記した。
  - `epsilon_momentum` は明示的な選択のまま残す。試験した条件の参照ソフトの出力は、全項で `k_total` を使い、実部の分子に分散前のエネルギーを使う候補の式と一致した。公表された式のままでは、`k_total` も不合格だった。

## 5. 実装単位の案（G1の後）

- 関数 `effective_cross_section_fixed_depth(material, electron_energy_eV, loss_eV, depth_A, theta_deg=0.0, hole_charge=1.0, epsilon_momentum=...)`。項別の値、`total`、`no_hole`、`hole` を返す。最初の版は θ ≠ 0 を拒否する。
- `epsilon_momentum` は `"k_parallel"`（原著 p. 1614右の制約 ε(k,ω) = ε(k∥,ω) をそのまま使う。印刷された閉形式はこの値）か `"k_total"`（k = (k∥² + Ω0²)^{1/2}。原著が述べる θ = 0 の極限はこの場合だけ成り立つ）のどちらかを明示して選ぶ。暗黙の既定値は置かない。既定にするかどうかは、§4.2の比較の結果を見て利用者が決める。
- θ = 0 の積分下限は、桁落ちしない k∥₋² = (s − r)³(3s + r)/(4s²H)（s = √E0、r = √(E0 − ħω)）で計算する（式レビューA4）。
- CLI `xpsloss xps-fixed-depth`。`run.json` には新しいモデルID（例 `simonsen1997_fixed_depth_v0`）、θ、a、x、正孔の電荷、εの運動量引数、速度の扱い（非相対論）、成分の定義を記録する。
- 未実装の一覧から外すのは「固定深さ・法線出射の表面・正孔・真空中の項」だけとする。深さ平均（式(18)）、スペクトル（式(19)）、斜出射は未実装のまま残す。

## 6. 未確定の点

- Q1: ε の運動量引数。§4.2の比較で、参照ソフトがどちらを使っているかを判断する。原著が理由を述べた文献（参考文献5: Yubero, Sanz, Ramskov, Tougaard, PRB 53, 9719 (1996)）は論文庫に未収録。
- 原著が「正孔なし・θ = 0 で全てのE0とaについて一致する」とした模型 A+ の出典、参考文献4（Yubero, Tougaard, PRB 46, 2486 (1992)）も未収録。入手できれば、正孔なしの値の外部照合に使える。
- 参照ソフトの速度が非相対論か相対論か（比較の結果から推定するだけになる）。

参照ソフトの出力は公開しないと決めた（2026-11-19、[NOTICES.md](../NOTICES.md)）。
