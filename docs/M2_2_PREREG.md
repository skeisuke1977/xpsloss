## 2. 共通の条件

- E0 = 1000 eV（UE だけ 3 eV）、出射角 0°。
- 基本の数値設定: epsabs \(10^{-12}\) Å⁻¹ eV⁻¹、epsrel \(10^{-9}\)、limit 200 を API と CLI で明示する。
- 基本の損失格子 G499: \(T=0.2i\) eV（\(i=1,\ldots,499\)）。
- 予算 \(B_j=\max(\varepsilon_{\rm abs},\varepsilon_{\rm rel}|K_{j,\rm ref}|)\)。\(j\) は8項、`no_hole`、`hole`、`total` の11出力。
- 運動量の指定は `k_parallel` と `k_total`。正孔電荷 \(Q_h\) は 0、0.5、1（V11 では −0.5 と 1.5 も）。

## 4. 独立な参照値（実装担当とは別の担当が作る）

- **作る担当:** 実装担当（Codex）とは別の担当。パッケージ `xpsloss` の KK、閉形式、求積、係数の関数を使わない。ELF（E1）、硬いギャップの KK（E4a の主値）、式(13)–(16)の各項を自分で書き、多倍長（mpmath、作業精度 50 桁以上）で計算する。`k_parallel` では、凍結した `tests/xps_route_b_reference.py` の \(k_\perp\) の核を呼ぶ別の積分器で、\(h=-F\) から係数を直接作る経路（I3 型）も作る。
- **参照点:** Si と S0 で、深さ 2、10、50 Å、両方の指定（I3 型は `k_parallel` のみ）、損失 \(T\) = 0.2、0.4、1.0、\(g-10^{-3}\)、\(g-10^{-6}\)、\(g+10^{-6}\)、\(g+10^{-3}\)、1.2、2、5、11、16.8、17、30、60、99.8 eV、8項と単位電荷の成分。N1 の \(T=4\) eV（10 Å、両方の指定）。V13 用に、分散ありで両方の指定の差が \(10^3B_j\) 以上ある点を参照点から選んで記録する。
- **参照の不確かさ:** 作業精度を変えた計算（50 桁と 80 桁）と、積分の分割を倍にした計算の差から \(u_j\) を見積もり、\(u_j\le0.01B_j\) を満たすことを確かめる。満たさない点は細かくして計算し直す。恒等的に 0 の量には解析値と \(u_j=0\) を使う。
- **凍結:** 生成スクリプト `benchmarks/numerics/m22/generate_references_m22.py`、参照値 `benchmarks/numerics/m22/references_m22.json`（入力、条件、各出力、\(u_j\)、計算法、ライブラリの版を含む）、比較の試験 `tests/test_m22_reference.py` を同じ担当が書く。参照値の SHA-256 をこの文書の付録に記録してから、実装と比べる。
