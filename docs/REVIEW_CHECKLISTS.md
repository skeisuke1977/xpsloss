# レビュー項目（M2）

作成日: 2026-11-19。M2の実装の前と後に、実装担当とは別の担当へ渡すための項目表である。レビューの結論は `docs/VALIDATION.md` に、項目番号を付けて記録する。

## 共通の約束

- レビュー担当には、原典（ページ画像、論文庫のキー）とレビュー対象だけを渡す。実装担当や依頼者の結論は渡さない。
- 指摘には重大度（blocker / major / minor）と、根拠の種類（原画像 / 自分の導出 / 数値の検算 / 推論）を付ける。
- 両者が同意したことは、物理的な正しさの根拠にならない。解析解、独立な数値計算、原典、参照ソフトの出力で判定する。
- レビュー担当は対象のファイルを編集しない。必要な計算は自分の作業用フォルダで行い、使ったコードを報告に添える。

## B. 実装後のレビュー（M2-1）

渡すもの: `docs/M1_EQUATION_MAP.md`、`docs/M2_FIRST_CASE.md`、実装のコードとテスト、テストの実行結果。原著のページ画像も渡す。

| 番号 | 項目 | 確かめ方 |
| --- | --- | --- |
| B1 | コードの各項が、式の対応表の行（式番号と項記号）に1対1で対応する。表にない項がない | コードを読み、表の行番号を付けた一覧を作る |
| B2 | 単位の換算 | E0 から v、v⊥、v∥、ω⊥、Ω0 への換算。非相対論の E0 = ½mv² を使い、その旨を記録している |
| B3 | 小さな損失での桁落ち | θ = 0 では Ω0 = ω/v で、k∥₋ = (k₋² − ω²/v²)^{1/2} が小さくなる。この差を安定に計算している |
| B4 | a が大きいときの打ち消し | (e^{−k∥a ∓ iΩ0a} − 1) などの差で桁落ちしない。I1 の a = 10⁵ Å が数値誤差で崩れない |
| B5 | δ項の扱い | ħω > 0 の格子だけを受け付け、πδ(ω⊥) を落としたことを記録している。ħω = 0 を拒否する |
| B6 | εの運動量引数 | `epsilon_momentum` が明示的に選ばれ、`run.json` に記録される。暗黙の既定値がない |
| B7 | 誘電応答の再利用 | ギャップのない材料では解析式を使う。ギャップのある材料（M2-2）では M1 の KK・ギャップ端の拒否・警告がそのまま働く |
| B8 | テストの中身 | `M2_FIRST_CASE.md` §4.1 の I1–I8 があり、I3（独立な第二の経路）が実装担当とは別の担当のコードである。許容幅が文書と一致する |
| B9 | 出力の記録 | `run.json` にモデルID、θ、a、x、正孔の電荷、εの運動量引数、速度の扱い、成分の定義、未実装の一覧、`queels_xps_equivalence: false` がある |
| B10 | 範囲の主張 | README、VALIDATION、capabilities が「実装・テスト・別担当のレビュー・外部照合」を区別している。参照ソフトとの比較が済む前に一致を主張していない |
| B11 | 第三者の物 | QUEELS/QUASES のコード、DLL、出力ファイル、図版をリポジトリに含めていない |
| B12 | 失敗時の振る舞い | θ ≠ 0、a ≤ 0、E0 ≤ ħω、非有限数を、計算の前にJSONのエラーで拒否する。既存の出力ディレクトリを上書きしない |
