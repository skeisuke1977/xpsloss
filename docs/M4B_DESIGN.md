## 0. 要約

- **主模型は「最初の損失は M4a の全核、その後の損失は 13a の項だけ」（`first_loss_13a_chain_v0`、以下 B1）。** 1次は M4a の \(J_1\) とビット単位で同じ。正孔・干渉・表面・真空の項は軌道につき高々1回。非負の一次線と非負の核から作る全量は、各次数で負にならない。
- **根拠の中心は原著の留保である。** Simonsen1997 p.1615 は、式(18)の核は「最初の非弾性散乱だけを表す。内因性の部分を含み、それは残りと分けられないので、繰り返しの畳み込みで全スペクトルを作れない」と書く（3人が本文で確認）。QUEELS-XPS の手引き（Tougaard2011 p.22）も「理論は原理的に多重の非弾性散乱に当てはまらない」と書いたうえで、比較のために全核の自己畳み込みを加える。
- **文献の全核の繰り返しは、係数が文献の間で食い違う。** 核を \(E_0\) に固定して形式的に展開すると、Pauly2016 式(7)・Pauly2023 式(1)の逆は各次数の係数 1、Pauly2023 式(5)は 2次に \(\lambda^2/2\)。論文庫の中の記述（Pauly2016 p.5、Pauly2019 p.2）は係数 1 と整合し、式(5)の \(1/2\) だけが孤立している。全核の繰り返しは非公開の参照の模型にだけ置く（利用者のレビューの指摘「全核をそのまま繰り返し畳み込まない」に従う）。
- **窓 \([a,b]\)（\(a>0\)）のもとで、有限の出力に届く次数は有限**（\(n\le(p_{\max}-d_{\min})/a\)）。ただし実測の条件では数十から百を超えるので、**通常は整数の `max_order`（必須）と、落とした次数の上界で使う。** 上界を利用者が明示した許容と比べる判定を足す（既定値なし）。
- **数値は M4a のパネル（17 点の補間）どうしの畳み込みを区間ごとのガウス求積で求め、`_fold` と同じ幾何とセルの規則で畳む**（誤差を3つに分けて運ぶ高次用の非公開の関数。各次数で最終の網に1回。§6.1）。1次の核の評価は M4a と同じ回数。高次の誤差は「1次から継承した分」「途中の次数から伝わった分」「その次数の網の分」に分けて返し、継承の分が予算を超えたら理由つきで止める（1次を作り直さない）。FFT は独立な参照の経路にだけ使う。試走（§14）では、Al 2p を想定した 0.1 eV と 0.2 eV のビンで、\(N=4\) が打ち切りの許容、局所と継承の判定を同時に満たした（U5 の採る条件は条件つきで満たす）。
- **束縛エネルギーは入出力の変換だけ**（\(E=C-B\)。\(C\) は光子エネルギーと明示のずれ、または校正の対応点から。推測しない。補正は記録だけ）。
- **最初の実測は、清浄な Al 金属の Al 2p と 2s（単色 Al Kα、法線）。** 準位ごとに \(E_0\) を決めて別々に計算し、同じ BE のビンで足してから、主線の帯に対する損失の帯の面積の比を比べる。模型を帯の比で見分けられるかは、データの前に合成の一次線で予測を計算して判定する（全軸の2次の面積は模型で開くが、帯の比では薄まる）。
- 工程は M4b-1（畳み込みと B1、KE の API・CLI）、M4b-2（束縛エネルギーの入出力と測定の記録）、M4b-3（識別力の事前の評価と、実測との比較）。利用者の決定は §12 の U1–U13。

## 3. 各次数の係数の導出 [計算]

深さによらない1回あたりの微分率 \(k(T)\)（Å⁻¹ eV⁻¹）を持つ経路上のポアソン過程、直線の軌道、一定の速度、弾性散乱なしとする。ほかに損失しない確率を \(e^{-x/L}\)、生成の密度を \(g(x)\) とする。窓の中の事象をちょうど \(n\) 回起こした寄与は \(e^{-x/L}x^nk_W^{*n}/n!\)（順序のある \(n\) 個の位置の体積が \(x^n/n!\)）。ゼロ次で割った \(k_W^{*n}\) の係数は

\[
c_n[g]=\frac{\int_0^\infty g(x)e^{-x/L}x^n\,dx}{n!\int_0^\infty g(x)e^{-x/L}\,dx}.
\]

| 仮定 | 係数 \(c_n\) |
| --- | --- |
| 経路長を1つの値 \(d\) に固定 | \(d^n/n!\)。Pauly2023 式(5)の 2次は \(d=\lambda\) のときに一致する |
| 半無限・一様な生成・法線 | \(\int_0^\infty x^ne^{-x/L}dx=n!L^{n+1}\) なので \(c_n=L^n\)（幾何級数）。核を固定した式(7)の逆と一致する |

- 次数 \(n\) に条件づけた経路の密度は \(p_n(x)=x^ne^{-x/L}/(n!L^{n+1})\)。\(p_1\) が式(18)の重みである。
- 深さに依存する核に戻ると、ゼロ次で割った1次は \(\int e^{-x/L}xK_{\rm eff}(x)\,dx/L=LK_{\rm sc}\)。\(m=L_w=L\) で M4a の \(J_1\) になる。
- 全損失の率なら \(1/L=\int k\) で、一様な深さの各次数の全軸の面積は一次線と等しい。全次数の和が規格化された確率にならないのは、半無限の一様な生成で生成の総量が無限だからである。窓の外の損失を減衰にだけ入れる長さでは比 \(r=LA_W\) が 1 より小さくなりうるが、任意の外部の \(L\) で \(r<1\) が従うわけではない。**乗数の規約（M4a-2）は、ここで初めて次数の間の比として意味を持つ。**

## 4. 多重化の定義

### 4.1 主模型 B1 `first_loss_13a_chain_v0`

\(K_{1,j}=m\,\mathbf 1_WK_{{\rm sc},j}(E_0,T;L_w)\)（M4a-2 の1次の核。\(j\) は 11 列）、\(R=m\,\mathbf 1_WK_{13a}(E_0,T)\) として

\[
C_{0}=\delta,\qquad C_{1,j}=K_{1,j},\qquad C_{n,j}=K_{1,j}*R^{*(n-1)}\ (n\ge2),\qquad J_{n,j}=\mathcal A_{C_{n,j}}F .
\]

- 書き換え: \(\bar g=K_{1,\rm total}-R\) とすると \(\sum_nC_{n,\rm total}=(\delta+\bar g)*\sum_{k\ge0}R^{*k}\)。\(\bar g\) は表面、真空、正孔、干渉、有限の経路の補正（13b）をまとめた「超過」で、軌道に高々1回入る。
- 全軸の面積: \(w_{n,j}=mA_j\,r^{n-1}\)、\(w=mA_{\rm total}\)、\(r=mA_{13a}\)。ビンと両側の外の総和はその \(S\) 倍。
- 成分: \(C_n\) は \(K_1\) に線形なので、各次数・各領域で `total = no_hole + hole_charge * hole` が厳密に成り立つ。8項の次数ごとの面積は単位正孔の列で保存し、正孔電荷を掛けるのは全量への寄与を求めるときだけ。
- 非負: 非負の \(F\)、\(K_{1,\rm total}\)、\(R\) から作る全量は全次数で非負。符号つきの成分（`hole`）、任意の正孔電荷、節の間で負に振れた補間には及ばない。`total` と 13a の核の負の値を、評価点の最小と連続区間の最小に分けて診断に残し、警告する。負の値を切らない。
- ID の名前: 繰り返しの核は 13a の列で、`k_parallel` では無限媒質のバルクの値と一般に違う（E7a の名前の規則）ので、「bulk」を名前に使わない。

| 16-e、16-h | 真空中の電子・正孔（固体内の経路長あたり） | 含む／正孔電荷倍 | 0 |

- [現行] 繰り返しの 13a は、1回目と同じ運動量の指定（`k_total` か `k_parallel`）の列を使う。法線では 13a 自体が深さによらない。分散のある `k_parallel` の 13a は無限媒質の DIIMFP と一般に違い、無分散では両指定が一致する（[式の対応表 §4.2、Q1](M1_EQUATION_MAP.md)）。分散のある `k_parallel` で警告を出す。
- `no_hole` 全体を繰り返す案は取らない。13b、15、16-e が何度も入り、原著 p.1612 の第2の指摘が残る。項を1つずつ多重化する案も取らない。[試算] Al の8項の \(L\times\) 面積は 13b −0.408、16-e +0.635、15-T3 −0.161 と、符号の違う大きな項が打ち消す。

### 4.2 乗数と重みの長さ

- 1次の \(L_w\)（重み）と \(m\)（乗数）は M4a-2 のまま（両方の重み、3つの乗数、種、分母の規則、区間、構造的なゼロ）。
- **繰り返しの因子にも同じ \(m\) を掛ける（推奨。U2）。** §3 の導出では、各次数の因子はゼロ損失の減衰の長さで、式(19)の乗数がそれに当たる。\(L_w\) は1回目の核の深さの重みにだけ入る。\(n\) 次の全体は \(m^n\) に比例する。
- S2（\(m=1/A_{\rm total}\)）では \(w=1\)、\(r=A_{13a}/A_{\rm total}\)（[試算] Al で約 0.58）。窓の 13a の重み（\(L_w=1/(A_{13a}+c)\)）で乗数 `weight_length` なら、理論の上では \(r=A_{13a}/(A_{13a}+c)\)。\(c=0\) で \(r=1\)（全軸の和が発散）、\(c>0\) で \(r<1\)。\(c\) は利用者の追加の減衰の率で、窓の外の実際の損失の率に当たるのは、そういう由来を与えた場合だけ（M4a-2 の W-c）。
- **計算の上の \(r\) と規約の上の \(r\) を分ける。** 窓の 13a の重みでは、\(\hat L_w\) は段αの \(A^\alpha_{13a}+c\) の逆数を丸めた値で、繰り返しの核は段βの \(A^\beta_{13a}\) を使う。両者は誤差の内で一致するだけで、ビット一致しない。\(\hat r=\hat mA^\beta_{13a}\) とその区間を返し、次数ごとの数値を恒等値で上書きしない。\(r\) を使う判定（全軸の落とした面積など）は、区間が 1 をまたげば「未確定」にする（§5）。
- \(m\ne L_w\) の組は §3 の導出の外（M4a-2 の W-len の警告を引き継ぐ）。

### 4.3 核のエネルギー

全次数で \(E_0\) に固定する（推奨。U3）。M4a と同じ。文献の式も核を1つ使う（Pauly2016 の印刷は検出の KE に依存する核で、固定はしていない。§2）。次数ごとに \(E_0-s\) へ下げると核の評価が次数の数だけ増え、平行移動の不変と面積の積の規則が崩れる。累積の損失の上端と \(E_0\) の比を記録し、0.1 を超えたら警告する。

### 4.4 近似の大きさ（模型の不確かさ）

軌道ごとにポアソンで数え、その後に深さで平均する模型 D を基準に置く（実装しない）。窓 \(W\) の中の事象だけを数え、固定深さ \(x\) で損失の数の密度を \(n_x(T)=xK_{13a}(T)+g(T;x)\)、\(g=x(K_{\rm total}-K_{13a})\)、平均の数を \(\nu(x)=\int_Wn_x\,dT\) とすると、軌道ごとの分布は \(e^{-\nu(x)}\exp_*[n_x]\)（畳み込みの指数）である。深さの重み \(e^{-\nu(x)}\) は一般に \(e^{-x/L}\) にならない。**以下の比較は、深さの重みを外部の \(q_L(x)=e^{-x/L}/L\) に置き換える近似のもとでの比較である**（M4a の式(19)と同じ置き換え）。

- **深さの相関を切ること:** \(m=L_w=L\)、\(B=LK_{13a}\)、\(\langle f\rangle=\int_0^\infty q_L(x)f(x)\,dx\)、\(\bar g=\langle g\rangle\)（§4.1 の \(K_1-R\) に等しい）とする。この重みでの D の2次は \(B^{*2}+B*\langle xg\rangle/L+\tfrac12\langle g*g\rangle\)、B1 は \(B^{*2}+B*\bar g\)。交差項の面積の比（D/B1）は、\(G(L)=\int_W\bar g\,dT\) が 0 でなく \(g\) が \(L\) に陽に依存しないとき \(1+LG'/G\)。[試算] Al で \(LG'/G=-0.006\)（比 0.994）、Si で −0.003（比 0.997）。**ただし、これは符号の違う大きな項の打ち消しである。** 項ごとの \(d(LA_j)/d\ln L\) は Al で 13b −0.103、14 −0.033、15-T1 +0.089、15-T3 −0.023、16-e +0.051、16-h +0.027（超過の面積 0.515 に対して −20 %、−6 %、+17 %、−4 %、+10 %、+5 %）で、Si も同じ形である。[解釈] 13b と 14 は体積プラズモンの位置、15-T1 と 16-e は表面プラズモンの位置に山を持つので、D の交差項は B1 に比べて体積＋体積（約 31 eV）の側が減り、体積＋表面（約 26 eV）の側が増える。大きさは B1 の2次の面積の約 1 割で、**形では B1 と C の差と同じ桁になりうる**（損失ごとの形は計算していない）。Codex の反例（超過が \(u(T)e^{-x/d}\) なら、\(p_{n-1}\) で平均した値は \(p_0\) で平均した値の \((1+L/d)^{-(n-1)}\) 倍）のとおり、超過が深さで速く減る場合には高次で大きくなりうる。
- **超過を高々1回にすること:** 超過もポアソンで数える模型 C（\(C_n=R*C_{n-1}+\bar g^{*n}/n!\)）との差は 2次で \(\tfrac12\bar g^{*2}\)。[試算] B1 の全軸の2次の面積に対して Al で 15.0 %、Si で 17.4 %。これは D の \(\tfrac12\langle g*g\rangle\) とは別の比較である（C は深さの相関も切る）。
- D の根拠（古典的な軌道の電荷が線形応答の媒質を励起すると、励起の数はポアソンになる）は Langreth (1970)、Hedin ら (1998) によると Fable が書いたが、論文庫になく未照合である。D を公開の主張に使わない。
- **結論:** B1 は原著の留保に最も字義どおりに沿う保守的な模型である。C との差（2次の面積で 15–17 %）と深さの相関の差（交差項の面積では 1 % 未満、形では同じ桁になりうる）を、模型の不確かさとして記録する。同じ \(q_L\) でも、D と C の2次の面積の差には交差項の差に加えて分散の項 \((\langle G_x^2\rangle-\langle G_x\rangle^2)/2\)（\(G_x=\int_Wg(T;x)\,dT\)）が残る。この項も \(D_2\) の中での再配分も求めていない（「1 % 未満」は交差項だけの話である）。C を足しても深さの相関の差は残るので、C は実測との比較で必要になれば後の工程で判断する（U1）。帯 \(D_2\) は約 26 eV と約 31 eV の両方を含むので、この再配分に鈍い。帯を2つに割らない（§8）。

## 5. 窓、次数、打ち切り、面積の定義

- **台:** \({\rm supp}\,C_n\subset[na,nb]\)、検出側の台は \([p_{\min}-nb,\ p_{\max}-na]\)。正の強度の一次線の台 \([p_{\min},p_{\max}]\) と出力の端 \(d_{\min}\) から、表示のビンに届く次数の上限は \(N_D=\max(0,\lfloor(p_{\max}-d_{\min})/a\rfloor)\)。境は厳密な有理数で判定し、等号の次数は残す（連続な核のビン積分は端の接触で 0）。一次線の強度がすべて 0 なら台は空で、`support_order = 0` とする。
- **実測の条件での大きさ:** Al（\(a=1\) eV）で全走査（BE 200 eV まで）を出すと \(N_D\approx127\)、比べる帯 \(D_2\) の上端（\(\Delta B=35\) eV）までに絞っても一次線の裾を含めて \(N_D\approx40\)。**実測の条件では、通常は整数の `max_order` と次の上界で使う。** 計算の出力の範囲は比べる帯を含む範囲にし、測定の取得の範囲と分ける（§8）。
- **`max_order`（必須、既定値なし）:**
  - 整数 \(N\ge1\): 次数 \(0..N\) を返す。`truncation.state` は、\(N\ge N_D\) なら `complete_on_display`、そうでなく利用者が `neglect_tolerance_fraction`（既定値なし。一次線の絶対の強度 \(S_{\rm abs}\) に対する比で、既存の `spectrum_epsabs_fraction` と同じ形。準位ごとの実行で一次線の強度が違っても値を変えずに済む）を与え、**表示のビンすべて**の上界がその \(S_{\rm abs}\) 倍以下なら `bounded_on_display`、台で完全でなく許容がなければ `truncated`（成功だが、落とした分は上界つきで返すだけ）。両側の外は判定に入れない（低い KE 側の外は \(d_D=-\infty\) で上界がない）。**成功の条件:** 台で完全なら上界は 0。許容がなければ、上界を診断に返して成功。許容があれば、有限の上界が許容以下のときだけ成功し、上界が許容を超えれば `MultipleLossConvergenceError("truncation_bound_exceeds_tolerance")`（必要な \(N\) の見積りつき）、使える \(\tau\) がないか上界が表せなければ `MultipleLossConvergenceError("truncation_bound_unavailable")`。上界は推定の誤差を入れた上界で、数学的な保証ではない（U4 の文に書く）。BE の入力では、BE の帯の高い BE の端が \(d_D\) に当たる。**1回の実行の許容は、その実行の \(S_{\rm abs}\) に対する比で判定する。** 準位ごとの実行を足した帯の許容は API の外（M4b-3 の比較の手順書）で別に判定する（§8）。
  - `"display_support"`: \(N=N_D\)。資源の上限を超えるなら、必要な次数と量を示して拒否する（§6.3 の段ごとの検査）。
- **落とした次数の上界（領域ごと）[計算]:** 領域 \(D\) の下端を \(d_D\)、\(U_D=p_{\max}-d_D\)、\(\Lambda_f(\tau)=\int_We^{-\tau t}|f(t)|\,dt\)（eV⁻¹ の \(\tau>0\)）とすると、\(\Lambda_R(\tau)<1\) の任意の \(\tau\) で、損失 \(\le U_D\) に落ちる次数 \(>N\) の絶対質量は \(S_{\rm abs}\,e^{\tau U_D}\Lambda_{K_1}(\tau)\Lambda_R(\tau)^N/(1-\Lambda_R(\tau))\) 以下（\(s\le U_D\) で \(1\le e^{\tau(U_D-s)}\)、各次数の絶対質量は \(S_{\rm abs}e^{\tau U_D}\Lambda_{K_1}\Lambda_R^{n-1}\) 以下、\(n>N\) で和）。**これはビンごとの値ではなく、「領域 \(D\) とそれより高い KE 側の全部に落ちる量」の累積の上界である**（最も低い KE の表示のビンの値が全体を決める）。診断の名前と説明にそう書く。
  - **入力の上側の値:** \(\Lambda_f\) はパネルごとの上側の見積り \(\sum_{\rm パネル}\big(\int_{\rm パネル}e^{-\tau t}|\hat f(t)|\,dt+e^{-\tau t_{\rm lo}}e_{\rm パネル}\big)\) で作る（\(t_{\rm lo}\) はパネルの左端）。値の部分は §6.2 の絶対値の積分の方法（上側の包絡か符号一定の区間）を重み \(e^{-\tau t}\) つきで使い、上へ丸める。左端の因子は誤差の項にだけ掛ける（値の部分にも左端の因子を使うと、パネルが 1–3 枚の核で上界が数百–数千倍緩くなる。§14 の D6）。点の値を指数の積分に代入するだけにしない。乗数の区間の上端を含める。
  - **\(\tau\) の選び方:** **等比の**格子 \(10^{-3}\) から \(40/a\) eV⁻¹ まで、1桁 20 点（試走 T6 で、箱形の核の連続な最小に対して最大 1.19 倍。上端を \(4/a\) にすると最大 10 倍緩い行がある）で上界の最小を取る。効く \(\tau\) は損失の山の位置の逆数の桁で、\(1/a\) よりずっと小さい。\(\|R\|_1\) の推定の上端が 1 より小さいときだけ、\(\tau\to0\) の極限（全軸の上界 \(S_{\rm abs}\|K_1\|_1\|R\|_1^N/(1-\|R\|_1)\)）も候補に入れる（符号が変わる核では \(\int R<1\) だけでは足りない）。\(1-\Lambda_R\) の正は上側の値で判定し、外向きに丸める。上界は対数で計算し、binary64 であふれる場合も「表せない」に含める（§14 の D7）。表せなければ `null` と理由。上流が推定の誤差なので、上界も「推定の誤差を入れた上界」と書く（M4a と同じ基準）。台で完全なら厳密に 0。[試算、合成の核（窓 \([1,50]\)、15.3 eV の Drude 型の \(R\)、10.6 eV の山の超過、δ の一次線）] \(U_D=35\) eV、\(N=3\) で、真の落とした量 \(1.6\times10^{-5}\) に対し、細かい等比の格子の最小は \(2.0\times10^{-4}\)（約 13 倍）、等差の格子 \(\tau a\in\{1..40\}\) の最小は 0.89（約 \(6\times10^4\) 倍）。細かい格子での上界は、\(U_D=35\) eV で \(N=3\)、4 が \(2.046\times10^{-4}\)、\(1.635\times10^{-7}\)、\(U_D=40\) eV で \(2.037\times10^{-3}\)、\(2.402\times10^{-6}\)（Codex が再計算。格子の上の核の和による試算で、実装のパネルの左端と誤差の包絡による上界は Al の試走で確かめる）。
  - 符号つきの核にも絶対値で使える。
  - \(N_D\) と `complete_on_display` の境は、計算の軸（丸めた後の KE の座標）の厳密な差で判定する。**BE の入力では、元の BE の厳密な差でも同じ量を求め、主張を弱い側に取る**（第6版）: 台の次数は2つの側の大きい方 \(S=\max(N_D^{\rm BE},N_D^{\rm KE})\)（`"display_support"` は \(N=S\)）。表示のビンごとに、そのビンの高い BE の端までの損失の幅 \(U\) を2つの側で求め、上界が台を根拠に厳密に 0（`complete`）になるのは、両方の側で \(U<(N+1)a\) のときだけ（等号は届くとみなす）。上界の指数に使う \(U\) は2つの側の大きい方を上へ丸めた値。`complete_on_display` は \(N\ge S\) のときだけ。台が空なら両側の次数は 0 とする。計算した次数 \(n\le N\) では一次線の台の各点と表示の各端の差の \(na\)、\(nb\) に対する大小・等号を、次の次数では各ビンの幅 \(U\) の \((N+1)a\) に対する大小・等号を2つの側で比べ、次の次数の到達の違いも別に記録する。次数か大小・等号が違えば警告 `axis_conversion_support_disagreement` を1件出し、違いの全件数と順序つきの先頭 8 例を診断に残す（拒否しない）。返す数値は丸めた KE の座標の問題の値で、換算の丸め（`rounding_max_eV`）は返す誤差に入れない。[反例] \(C=8192\) eV、一次線は \(B=0\) の δ、出力の BE の端 \([0,\,2+2^{-43}]\)、\(a=1+2^{-45}\) eV では、全座標の合併は単射だが、高い BE の端の KE は 8190 に丸まり、元の BE の差では \(N_D=2\)、丸めた KE の差では \(N_D=1\) になる。KE の側だけを見ると \(N=1\) で元の BE のビンに対して誤って完全と表示しうるので、`truncated` と正の上界を返す（0 でない核、許容なし、\(N=1\) のとき）。第5版までは、食い違いを `MultipleLossInputError("axis_conversion_changes_support")` で拒否するとしていた。十進の BE の格子でも食い違いは珍しくなく（M4b-2 の事前登録の確かめで、実測に近い 720 通りのうち 60 通り）、入力を動かす以外に避けられない拒否になるので改めた。
- **両側の外:** 計算した次数は M4a と同じく直接に積分する。低い KE 側の外は、表示が完全でも全次数は有限にならない。`outside.low` に落とした次数を足さない。
- **落とした次数の全軸の面積（`neglected_total_area`）:** 判定の順は、(1) \(S=0\) か1回目の核が恒等的にゼロなら 0。(2) \(R=0\) なら、\(N=0\) で \(Sw\)、\(N\ge1\) で 0。(3) 非負の繰り返しの核で \(Sw\ne0\) なら、計算の \(r\) の区間 \([r_-,r_+]\) で、\(r_+<1\) のとき \(S\,w\,r^N/(1-r)\)（区間つき）、\(r_-\ge1\) のとき `None` と理由 `diverges`、\(r_-<1\le r_+\) のとき `None` と理由 `undetermined`。符号つきの列（`hole` など）は代数の面積で、\(w_j=0\) でもビンの強度は残りうる。代数の面積が厳密に 0 と分かる列（例: \(S>0\)、\(R\ne0\)、\(K_{1,j}\not\equiv0\) で構造的に \(w_j=0\)）は代数の面積を 0 とし、丸めた面積が 0 になっただけの列と区別して記録する。絶対の質量には \(\|R\|_1<1\) を十分条件として \(S_{\rm abs}\|K_1\|_1\|R\|_1^N/(1-\|R\|_1)\) を使う。
- **規約の上の収束を別の欄にする（`convention_ratio`）:** 窓の 13a の重みと乗数 `weight_length` の組では、同じ \(A_{13a}>0\) から作る理論の比は \(c=0\) で厳密に 1（発散）、\(c>0\) で 1 未満（収束）である。この性質は段α・βの推定の区間で未確定にせず、`convention_ratio`（`exactly_one`、`below_one`、`not_determined_by_convention`）として計算の \(\hat r\) の区間と別に返す。外部の乗数と S2 では規約から決まらない。
- **窓の外の損失:** 評価しない。\(b\) より大きい1回の損失は含まない（2回の和が \(b\) を超えるのは普通に起こり、有効）。\(a\) より小さい損失は一次線の形が担うと仮定する（一次線の裾との二重の計上は §8）。
- **窓の下限への感度（面積、次数ごと）:** \(m\)、\(L_w\)、\(b\)、\(E_0\)、正孔電荷を固定した偏微分 \(h_{n,j}=-\partial_{\ln a}(mA_j\,r^{n-1})\)。\(h_{1,j}=m\,aK_j(a)\)（専用の分岐）、\(n\ge2\) で \(h_{n,j}=h_{1,j}r^{n-1}+(n-1)\,mA_j\,h_r\,r^{n-2}\)、\(h_r=m\,aK_{13a}(a)\)（\(r=0\) で \(r^{-1}\) を評価しない形）。S2 と窓の 13a の重みでは全微分と違う（M4a-2 の W-sens。S2 の \(w_1\) の全微分は 0）。[試算] Al（\(a=1\) eV）で \(h_1/w=2.5\%\)、\(h_r/r=0.04\%\)。ビンごとの片側の感度は1次だけ（M4a のまま）。実測の窓の走査は、窓を変えて解き直した差として別に記録する。
- **面積だけの入口:** `multiple_loss_order_areas` は一次線と出力の端を受け取らない。整数の `max_order` だけを受け付け、`"display_support"` は理由つきで拒否する。返すのは \(w_{n,j}\)、\(h_{n,j}\)、\(r\) とその誤差・区間。表示と外の診断は対象外。

## 6. 数値の方法

### 6.1 パネルの補間どうしの畳み込み

1. **1次:** M4a の `_run` を同じ引数で呼ぶ。非公開の受け取り口を足し、成功した実行の最終段（段β。段βの整合の判定と警告を含む成功の処理の後）で、そのパネル（(11,17) の値、点の誤差、補間の差、検証の残差）を一度だけ渡す。段αや未収束のときは渡さない。旧入口の演算の順、検証の点、戻り値は変えない（M4A 群のビット一致と、段βの供給の回数・物理の核の呼び出しの回数の計測で確かめる）。次数 0 と 1 の出力はこの結果をそのまま使う。
2. **次数 \(n\ge2\):** \(C_n(s)=\int C_{n-1}(s-t)R(t)\,dt\)。点 \(s\) の積分区間は \([\max(a,s-(n-1)b),\ \min(b,s-(n-1)a)]\)。\(R\) のパネルの端と、\(s\) から引き戻した \(C_{n-1}\) のパネルの端を併合し、各区間を 17 点のガウス・ルジャンドルで積分する（16 次×16 次の積は 32 次で、17 点則は 33 次まで厳密。内側の積分は丸めまで厳密）。出力の \(C_n\) は区分 16 次に補間し直すので、**全体は丸めまで厳密ではない**（\(C_2\) の真の次数は 33 まで）。移動する端 \(s-t_i\) と網の和は、二進の入力の厳密な差・和で扱う。
3. **網:** 内側のガウスの積分は、両方のパネルの列の全部の境で区切る（2の手順）。外側の網 \([na,nb]\) では、各因子の特異点（窓の端と、解析の入口の `jumps_eV`・`kinks_eV`）の \(n\) 個の和を必須の節にする。物理の入口では窓の端だけになり、\(ka+(n-k)b\)（\(k=0..n\)）。近似に使うパネルの内部の端の和（例: 内部の端 \(c\) があれば2次の \(a+c\)）も区分多項式の式が切り替わる候補だが、必須にせず二分に任せ、その費用を数える。節の候補の列挙にも上限を置く。**初めの網は必須の節だけで作り、二分に任せる**（試走 T2 で、「1次のパネルの最小の幅以下」の規則に比べてパネルが 1/4–1/40、畳み込みの費用が 1/2–1/60。二分の段は 2–6）。必須の節は \(k\) と \(n-k\) から有理数で作り、重複を除いてから1回だけ binary64 に丸める（浮動小数の和で作ると 1 ulp だけ違う節ができ、幅 1 ulp のパネルで誤って止まる。§14 の D5）。各パネルで 17 点と別の 16 検証点を評価し、検証の残差と下流の出力への寄与で二分する。節が表せないときの端の誤差と理由を決める。
4. **畳み込み:** 得た \(C_n\) を `Panel` に入れ、`_fold` と同じ `Geometry`、同じセル（9 点則、有理数の質量）、同じ誤差の項で領域ごとに畳む。誤差を継承・伝播・局所の3つに分けて運ぶため、高次用の非公開の関数にする（今の `_fold` は領域ごとに誤差を1本にして返す。§14 の D4）。既存の `_fold` の演算の列は変えない。**正式の畳み込みは各次数で最終の網に行う。** 網の二分の判定には、パネルの局所の残差と、領域の質量を binary64 の累積分布で求めた速い見積りを使い、最終の網の正式の畳み込みで予算をもう一度判定する。満たさなければ二分を足して畳み直し、資源の上限で止める。正式の畳み込みの回数を診断に残す（段ごとに正式に畳み直すと、0.1 eV のビンの Al 2p で高次の時間の大半を占めた。試走 T5）。パネルは \(m\) を掛けない値で持ち、有理数の \(m^n\) を渡して丸めを最後の1回にする。`_fold` が作るキーのうち、高次では衛星の3成分（`single_loss_*`）だけを読み、`zero_loss`、`spectrum`、`cutoff_sensitivity.*` は使わない（\(J_0\) の重複と誤った感度を避ける）。収支は高次用に新しく作る（`_finish` の収支は1次専用）。途中で検出のビンに戻さない。
5. B1 は \(K_1\) に線形なので 11 列のまま運ぶ。\(R\) は 13a の列で、同じパネルにある。

### 6.2 誤差と予算

- **点の誤差:** 各交差区間で誤差の包絡 \(\epsilon_{n-1}\)、\(\epsilon_R\) を作り、点 \(s\) で \(\epsilon_n(s)=\int\big(|\hat C_{n-1}(s-t)|\epsilon_R(t)+\epsilon_{n-1}(s-t)|\hat R(t)|+\epsilon_{n-1}(s-t)\epsilon_R(t)\big)dt+e^{\rm local}_n(s)\)。\(e^{\rm local}_n\) は新しい補間、検証の残差、求積の丸め、端の誤差。**継承と伝播の包絡は関数として評価して運ぶ:** 新しいパネルの 17 節と 16 検証点で、この積分を前の次数の包絡（パネルごとの定数の包絡。各パネルの節と検証点での値の最大）に対して求め、その最大をそのパネルの包絡とする。節の誤差を補間の基底の絶対値で次の次数へ運び直さない（運び直すと、次数ごとに 17 点のルベーグ関数の平均の分、約 2 倍ずつ膨らみ、継承の判定を数次で超える。試走 T3、§14 の D1）。補間の基底の絶対値は、節の誤差をビンへ移すセルの重みにだけ使う（M4a と同じ）。継承と伝播の分は節の `errors` で運び、`Panel` の検証の残差には局所の残差だけを入れる（検証点の誤差を入れると、継承の分がセルの2つの項に二重に入る。§14 の D4）。領域の誤差は、この点の誤差から `_fold` が作る1本だけにする（\(L^1\) の誤差と二重に数えない）。検証の残差を含む推定であり、数学的な保証とは書かない（M4a と同じ基準）。
  - **絶対値の積分:** 絶対値を取った補間多項式と補間の基底は区間の中でも符号が変わるので、17 点則の多項式の厳密さが及ばない（例: \(\int_{-1}^1|u|\,du=1\) を 17 点のガウス則でそのまま積分すると 0.994621594685）。区間ごとに係数・基底の絶対値から上側の包絡を作って積分するか、符号が一定の区間に分けて評価する。\(\int|\delta f|\) を符号つきの面積の誤差で代用しない。
  - **置き場所:** 節で加える局所の誤差と、節の間の補間・検証の誤差の置き場所を、現行の `_fold._cell`（`panel.errors` とは別に補間・検証の分を足す）に合わせて決め、二重に加えない。
- **面積の誤差:** \(L^1\) の伝播（Young の不等式）\(e_{n}\le\|\hat R\|_1e_{n-1}+\|\hat C_{n-1}\|_1e_R+e_{n-1}e_R+e^{\rm local}_n\) は、面積と §5 の上界にだけ使う。符号つきなので \(|\int\hat f|\) で代用しない。
- **誤差の3つの分け方:** 次数 \(n\) の誤差を、(i) 1次のパネルから継承した分 \(e^{\rm inh}_n\)、(ii) \(2..n-1\) 次の網で生じて伝わった分 \(e^{\rm prop}_n\)、(iii) \(n\) 次の網で生じた分 \(e^{\rm loc}_n\) に分けて返す（点の誤差の式の各項を、どの網に由来するかで3つに振り分けて運ぶ）。\(n\) 次の網の二分で減るのは (iii) だけで、(i) と (ii) は \(n\) 次に入る時点で固定されている。振り分けの規則: \(|\hat C_{n-1}|\epsilon_R\) と混合の項 \(\epsilon_{n-1}\epsilon_R\) は (i)（\(R\) の誤差は1次のパネルの誤差）、\(\epsilon_{n-1}|\hat R|\) は \(\epsilon_{n-1}\) の (i)、(ii)、(iii) の成分をそれぞれ (i)、(ii)、(ii) へ。混合の項は一度だけ数える。
  - **(iii) の判定:** 高次の設定 `order_epsrel`（\(\varepsilon_o\)）、`order_epsabs_fraction`（\(\eta_o\)）で \(\max(\eta_oS_{\rm abs},\varepsilon_o|y|)\) の内（面積は \(\max(\eta_o,\varepsilon_o|w_n|)\)）。満たすまで \(n\) 次の網を二分し、資源の上限で `order_budget_not_met`。
  - **(ii):** 運んだ点ごとの包絡から求めた実額を返す。合否の判定は課さない（前の次数の網を作り直さないので、判定しても直す手段がない）。ビン積分の予算だけからは節の間の包絡を復元できないので、「前の次数の予算で自動に抑えられる」とは書かない。
  - **(i) の判定:** 1次の設定 `epsrel`（\(\varepsilon\)）、`spectrum_epsabs_fraction`（\(\eta\)）、`area_epsabs`（\(\eta_A\)、Å⁻¹）で判定する。固定の乗数で \(\hat w_{{\rm abs},j}=\|\hat K_{1,j}\|_1\)、\(\hat r_{\rm abs}=\|\hat R\|_1\)（\(K_1\) と \(R\) は eV⁻¹ で \(m\) を含むので、損失で積分したノルムは無次元。\(m\) を二度掛けない）、\(\phi_{n,j}=\hat r_{\rm abs}^{\,n-1}+(n-1)\hat w_{{\rm abs},j}\hat r_{\rm abs}^{\,n-2}\) とする。ビンは \(\max(\phi_{n,j}\eta S_{\rm abs},\ n\varepsilon|y|)\)、無次元の面積は \(\max(\phi_{n,j}\hat m\eta_A,\ n\varepsilon|w_{n,j}|)\)（1次の無次元の面積の絶対の予算は \(\hat m\eta_A\)）。列ごとに判定するときは、その列のノルムを使う。相対の側の \(n\) は、\(w_n=wr^{n-1}\) の相対誤差が \(e_w/w+(n-1)e_r/r\) で、1次が予算いっぱいなら \(n\varepsilon\) になるため。絶対の側の \(\phi_n\) は、2つの因子の誤差が同じ \(\delta\) のとき \(n\) 次で \(\phi_n\delta\) になるため（Al の外部の長さで2次は \(1.95\delta\)）。どちらも1次の近似の許容の方針で、積の保証の値ではない（2次の積でも混合の項 \(\delta^2\) が加わる）。合否には §6.2 の混合の項を入れた推定の値を使う。超えれば `MultipleLossConvergenceError("inherited_error_exceeds_order_budget")`（次数つき。相対と絶対のどちらで超えたか、したがって `epsrel` と絶対の設定のどちらを下げるべきかを分けて知らせる）。
  - **面積だけの入口:** 一次線がないので \(S_{\rm abs}\) を使わず、無次元の面積の予算だけを使う。
  - **1次のパネルは作り直さない**（1次の結果と核の呼び出しの回数を M4a のまま保つ）。前の次数の網も作り直さないので、(i) が超えた場合は、超えた側（相対か絶対か）と次数を付けて止める。低い次数の網に戻って二分する方法と、高次用に1次の核を作り直す経路は、必要になれば後の工程の候補。
  - **利用者に見える精度:** 各次数の局所の判定と継承の判定を通っても、伝播の分と乗数の区間で、高次の返す誤差は1次の設定より大きくなりうる。単純な倍数の目安は約束しない。返す誤差の内訳（継承、伝播、局所、乗数の区間）を必ず返し、U5 の文にもそう書く。
- **高次の予算の既定:** \(\varepsilon_o=10^{-6}\)、\(\eta_o=10^{-9}\)（M4a と同じ）。緩い値（\(10^{-5}\)、\(10^{-7}\)）はパネルが 3 割減るだけで畳み込みの回数は同じで、返す誤差が 1 桁以上増える（試走 T3）。
- **(i) の余裕は入力で 2 桁動く（§14 の D2）:** 面積の `total` では、Al の1次の推定の相対誤差が約 \(5\times10^{-8}\) で約 20 倍の余裕がある。ビンと符号つきの成分（`hole`、15-T2 の列）では、1次がすでに自分の予算の 0.8–0.99 に来ていることがあり、符号つきの成分では \(|\hat K_{\rm hole}|*\epsilon_R\) が打ち消し合わないので、相対の側 \(n\varepsilon|y|\) を数次で超えうる（試走 T3: δ の一次線、0.5 eV のビン、既定の `epsrel` で `hole` の3次が予算の 1.45 倍）。**判定の規則は変えない:** 超えたら `inherited_error_exceeds_order_budget` で止め、相対の側なら `epsrel` を下げるよう理由に書く（`epsrel=10^{-7}` で全成分の比が 0.02 以下、1次の核の点は約 4 割増し）。符号つきの成分だけ別の尺度で測る案は、1次（M4a）と予算の意味が変わるので採らない。幅のある一次線（Al 2p と 2s を想定した T5）では比は 0.006–0.45 だった。
- **和:** 合計のスペクトルの誤差は次数の誤差の絶対和に、加算の丸めを足す。打ち消しで予算を稼がない。有限和そのものに予算を課すか、誤差の和を返すだけにするかは事前登録で決める（候補: 返すだけ。各次数の判定が合否を決める）。
- **乗数の区間:** 正の区間 \([m_-,m_+]\) で \((m/\hat m)^n\) は単調なので \(\rho_n=\max(1-(m_-/\hat m)^n,\ (m_+/\hat m)^n-1)\)（厳密な比の累乗から上へ丸める）。再帰には固定の \(\hat m\)、\(\hat L_w\) の誤差だけを渡し、乗数の区間は各次数の最終の出力に1回だけ掛ける：返す誤差は \(e_y+\rho_n(|\hat y|+e_y)\) を上へ丸める（M4a-2 の規則の \(n\) 次版）。S2 の1次の全軸の面積の誤差は既存の規則。\(L_w\) の区間が核 \(K(L_w)\) の形を動かす分は、M4a-2 と同じく誤差に入れない。S2 で正孔電荷ごとに \(m\) を決め直す走査に、固定 \(m\) の電荷の線形性を課さない。

### 6.3 費用と資源の上限

- **物理の核:** M4a と同じ回数（[試算] 窓の面積で Al 4–8 秒、Si 12–14 秒。段βは Al で 40 枚、最小幅 0.5 eV、Si で 24–26 枚）。
- **畳み込み:** 次数 \(n\) の1段で約 \(33P_n\times17(P+P_{n-1})\) 回の多項式の評価。§6.1 の3の「1次の最小の幅以下」なら Al の2次で少なくとも 196 枚、10次で 980 枚（\(P_n\approx40n\) より多い）。\(P=40\)、\(P_n=40n\) でも1段 \(9\times10^5n^2\)、次数 10 までの合計 \(3.4\times10^8\)、40 次で \(2\times10^{10}\)。これは「1次の最小の幅以下」の網の数で、採った必須の節だけの網では、試走で Al の 2–10 次が 21–46 枚、求積点の評価は 10 次までの累計で \(1.4\times10^7\) だった（§14 の D3）。
- **`_fold`:** [試算] `_fold._fold` の1回（1次の1段）が、一次線 50 ビン・出力 100 ビン・パネル 40 枚で 9.8 秒、一次線 200 ビン・出力 400 ビン・パネル 40 枚で 172.9 秒（`Geometry.mass` が一次線の全ビンを有理数で走査するため）。実測の大きさの一次線では、物理の核より `_fold` が支配する（M4a 自体も遅い）。試走 T4 の実測は 7.0 秒と 209.6 秒で同じ桁、1セルあたり約 40 µs＋6.2 µs×（一次線のビン数）。だから正式の畳み込みは各次数で最終の網に行う（§6.1 の4）。試走 T5（Al 2p を想定、0.1 eV のビン、\(N=4\)）では1次が 65 秒（M4a のまま）、高次は二分の段ごとに畳み直すと 351 秒で、各次数1回なら約 1 分の見込み。
- **資源の検査を3段に分ける:** (i) 入力だけで決まる超過（要求した次数、作業量の下限）は段αの前に `MultipleLossInputError`（`order_limit_exceeded`、`work_lower_bound_exceeded`）で拒否する。(ii) 段βの後に分かる超過（実際のパネルの数と最小の幅から見積もる高次の網と作業量）は、高次の配列を確保する前に `MultipleLossConvergenceError("convolution_work_limit_exceeded")`。(iii) 適応の途中での超過は `convolution_work_limit_reached`。上限は `order_limit=64`、`max_convolution_points=2×10^8`（求積点の評価の数＝17×交差区間の数の、2次から \(N\) 次までの累計）、`max_cells=2,000,000`（次数ごと）で、資源の上限であって物理の既定値ではない（試走 T7。Al の 6–10 次の実績は求積点 \(1.0\)–\(1.4\times10^7\)、セルは次数ごとに 45,000 以下）。入力だけで決まる作業量の下限と、段βの後の見積りの式は、事前登録で固定する。
- **試走で測ること:** 初めと最後のパネルの数、実際の交差区間の数、11 列の処理、両側の外を含むセルの数、時間とメモリ、`_fold` の時間（一次線と出力の大きさを変えて）、高次の初めの網の規則の比較。

### 6.4 選ばなかった方法

| 方法 | 理由 |
| --- | --- |
| 一様な格子と FFT | 核が \(a\)、\(b\) で不連続で、点の値の離散化は1次の精度。M4a と同じ厳しさの誤差を出せず、δ とビン端の厳密な扱いと合わない。**独立な参照の経路に使う** |
| フーリエ空間で級数を閉じた式で足す | 次数ごとの出力が出ない。\(r\ge1\) で使えない。恒等式の参照に使う |
| 出力のビンを次の次数の一次線に使い回す | ビン内一様の近似が入り、両側の外を運べない |
| 区分多項式の係数での厳密な畳み込み | 節と次数が次数とともに増える |
| 次数ごとに核のエネルギーを下げる | §4.3 |
| 模型 D を直接 | 深さに依存する核どうしの積（運動量の2重積分）が要る |
| 高次用に1次の核のパネルを作り直す | 核の呼び出しが増え、1次と別の表を持つことになる。継承の分の判定（§6.2）で足りなければ後の候補 |

## 7. 束縛エネルギーの入出力（D10）

内部と既存の API は運動エネルギー（KE）のまま。束縛エネルギー（BE）は入口と出口の変換だけにする。

- **変換:** 1回の測定で \(E=C-B\)。\(B\) はフェルミ準位を基準に正の向き（損失は \(B\mapsto B+s\)）。密度の変換は \(|dE/dB|=1\)（BE の密度は返す面積をその BE の幅で割る）。
- **\(C\) の与え方（排他。どちらかが必須）:**

| `reference.kind` | 与えるもの | \(C\) |
| --- | --- | --- |
| `photon_and_offset` | `photon_energy_eV`（\(h\nu\)）と `kinetic_energy_offset_eV`（\(\phi\)。KE が共通のフェルミ準位から測った校正済みの値なら 0、分光器の真空準位から測った値なら既知の分光器の仕事関数） | \(h\nu-\phi\) |
| `paired_anchor` | 同じ校正の座標での対応点 `binding_anchor_eV`（\(B_\star\)）と `kinetic_anchor_eV`（\(E_\star\)）、線の名前、出典 | \(B_\star+E_\star\) |

- **必須の記録:** `photon_energy_eV` は、どちらの形でも測定ごとに必須（D10。線源の名前から数値を補わない）。`paired_anchor` では \(h\nu-(B_\star+E_\star)\) を「含意されるずれ」として診断に残す（補正には使わない）。`source`（線源、単色か、サテライトの扱い）、`calibration`（校正の線、基準の値、測った値、適用したずれ）、`charge_correction`（有無、方法、量）、`core_level`、出射角と取り込み角。記録の欄は `"not_recorded"` を許し、警告する。数値の光子エネルギーと、選んだ基準の形の値は `"not_recorded"` にできない。
- **推測しない:** 試料の仕事関数、帯電の量、分析器のバイアス、接触電位は補わない。**パッケージは軸をずらさない**（U6）。入力はすでに校正・補正の済んだ目盛りにあるとみなし、何をしたかを記録する。真空準位を基準にした BE は扱わない。
- **\(E_0\):** これまでどおり `electron_energy_eV` を必ず明示する（BE から自動で決めない）。一次線の代表位置 `primary_reference_binding_eV` と選び方を記録し、\(C-B_{\rm ref}\) と \(E_0\) の差を診断に残す（M4a の「\(E_0\) が一次線の範囲にない」の警告も使う）。光子エネルギーや準位が違えば、実行を分けて \(E_0\) をそれぞれ与える（§8 の準位ごとの実行）。核を \(E_0\) に固定するので、全体を同じ量だけ動かす相対の量（衛星の相対面積、主線からの位置）は \(C\) によらない（連続の計算の性質）。
- **入口:** BE の負の値、減少の順のビン、強度・誤差の配列を受け付ける入口を、KE の型を作る前に置く（現行の KE の型は負の値を拒否する）。入力の BE の端を保存する。
- **丸めと並び:** 入力の数から \(C-B\) までを厳密な有理数で計算し、最後に1回だけ最も近い binary64 に丸める。**一次線の位置・ビンの端と出力の端の全部を合わせた異なる座標の集合で**、丸めの後の順序と重なりを検査し、壊れれば `axis_conversion_not_injective` で拒否する（元から等しい座標は許す）。[反例] \(C=8192\) eV、BE の端 \([0,1,2]\)、δ の位置 \(1+2^{-45}\) eV では、各配列は単独で単射だが、内部の境と δ がともに KE 8191 に丸まり、`Geometry.mass` で δ の所属が逆になる。丸めの最大を診断に残す。KE の昇順に並べ替えて計算し、出力は入力の向きに戻す。両側の外は `outside.high_binding`（内部の `outside.low`、低い KE 側）と `outside.low_binding`（高い KE 側）と呼ぶ。境の上の δ は KE の左閉右開の規則を鏡に写す（内部の境は低い BE 側のビンへ、全体の両端は端のビンへ）。
- **理論の計算**（KE を直接に与える）では、光源も BE の基準も求めない。
- **スキーマ:** 測定の入力は新しい識別子（例: `xpsloss-measured-spectrum-v0`）。M4a の KE のスキーマは変えない。

## 8. 最初の実測データの条件と検証の範囲（D10）

データは利用者が用意する。条件の案（M4b-3 の事前登録で、データの衛星の強度を見る前に固定する）:

| 項目 | 案 |
| --- | --- |
| 材料・線 | 清浄な Al 金属の Al 2p と Al 2s を同じ走査で（BE 約 60–200 eV）。2p（約 73 eV）と 2s（約 118 eV）の間隔は体積プラズモン3回分（約 45–47 eV）に近い。**準位ごとに別の実行にする**（D10。準位ごとに \(E_0\)、核、\(L_w\)、\(m\)、S2 の分母が違いうる）。\(F_{2p}\)（二重線を含む）と \(F_{2s}\) に一次の強度と幅を別に与え、同じ BE の基準と出力のビンで、それぞれの \(E_{0,\ell}\) で計算し、次数・ビンごとに \(J_{n,2p}+J_{n,2s}\) を足してから帯の比を取る。2つの実行の入力、相対強度の独立な根拠、共通の校正の共分散を記録する。**足した後の規則:** 返す誤差は2つの実行の絶対和。準位ごとの表示の状態をそのまま保存する（弱い方を採るだけでは足した帯の合否は決まらない）。各模型・各帯 \(D\) で、準位ごとの上界 \(B_{\ell,D}\) の和が帯の許容 \(T_D\) 以下か（\(\sum_\ell B_{\ell,D}\le T_D\)）を別に判定する。\(T_D\) の基準（例: 帯の面積に対する比）と単位は比較の前に固定する（例: 一次の強度の和が 100、帯の面積が 1 なら、上界の和 0.05 は一次の強度の 1 % の内でも帯の面積の 1 % を超える）。2s が表示に届く次数は、入力した有限の裾の低 BE の端と帯の高 BE の端から求める。合算は M4b-3 の比較の手順書（スクリプト）で行い、API には入れない。出力を \(\Delta B\le40\) eV に絞ると、2s の実行は主線（\(\Delta B\approx45\)）が出力の外にあり、表示に届くのはゼロ損失の裾が主になる（\(N_D\) は 2s の一次線の裾の低 BE の端による。例: \(a=1\) eV、帯の上端が \(\Delta B=40\) eV、2s の裾の下端が 42 eV なら \(N_D=0\)）。したがって 2s の一次線の裾の形（寿命の幅）は \(D_2\) の系統の幅の項目である。1つの \(E_0\) の計算は、中心の予測との差を見る感度の試験にだけ使う。次の候補は Si の 2p・2s |

| --- | --- | --- |
| 数値（どの条件でも） | 次数ごとの畳み込みが、与えた核と模型の定義に対して正しいこと | 模型の物理の妥当性（`physical_validity` は `not_established`） |

## 10. 検証の設計（事前登録の骨子）

参照は実装担当と別の担当が、パッケージを読み込まない生成器で作る（M4a の R-A の流儀）。実材料の参照だけは公開の M3a の点の値を使い、共有する部分を照合の範囲から外すことを明記する。内部に、核を呼び出し可能な形で渡す解析の入口（M4a の `integrate_window` に当たる）と、点の誤差と節の間の残差を注入する入口（M4a の `inject` に当たる）を置く。**恒等式の両辺を製品の畳み込みで作らない**（再帰の定義から恒等的に成り立ち、誤りを検出できない）。

| 群 | 内容 |
| --- | --- |
| RM-A1 箱形の核 | \(\kappa\mathbf 1_{[a,b]}\) の \(n\) 回の畳み込み（ずらした Irwin–Hall）。次数 1–6、非整列の端、両側の外を有理数で厳密に。区間ごとに多項式なので、丸めの水準の許容で比べる行を置く |
| RM-A2 傾けた箱 | \(\kappa e^{-\mu T}\mathbf 1_{[a,b]}\)。位置のずれと向きを検出 |
| RM-A3 2種の核 | \(K_1\) と 13a の列に別の形（幅の違う箱、正負の箱で `hole`）。幅の違う一様変数の CDF は分母 \(n!\prod h_i\)、端のずれの部分集合の和で符号は要素数の偶奇。列の取り違え、正孔電荷 0/1/2、実際に負の `hole` のビン |
| RM-A4 多項式の核 | 両方の因子が 9 次以上（できれば 16 次）の行を必ず入れる。例: 幅 \(\ell=b-a\)、\(u=2(t-a)/\ell-1\)、両核 \(1+P_9(u)\)、\(s=a+b\) で積は \(1-P_9(u)^2\)、厳密値 \(18\ell/19\)（9 点則は全点で \(P_9=0\) なので \(\ell\) を返す）。内側の積分の厳密さと、外側の補間し直しの誤差を別の行で試す |
| RM-A5 鋭い山 | 窓で切ったローレンツ型。多倍長の入れ子の求積（\(n\le3\)）。網の二分と誤差の見積り |
| RM-B 実材料 | ELF データ集の Al、Si、1000 eV、両運動量。公開の深さ平均の点の値から、別の経路（窓の端を格子点に置いた一様な格子と台形則、Richardson 外挿。端の和 \(2a\)、\(a+b\)、\(2b\) は別に扱う。直接の多重求積は3次で費用が大きすぎる。試走 T11）で \(n=2,3\) のビン。一次線は δ か 5 ビン以下、出力は 160 ビン以下（試走 T9）。参照の誤差を別に見積もり、必須のキーが得られない行を成功にしない |

| INV 逆変換 | B1: \((I-\mathcal A_R)J^{(N)}=(I+\mathcal A_{\bar g})F-\mathcal A_{K_1*R^{*N}}F\)。参照の生成器が、この式を損失の座標の累積（負の損失で 0、原点の δ の質量、\(R\) の台による遅延の積分）について既知の側から区分的に解き、その合計を製品の `spectrum` のビンと両側の外と比べる（製品のビンの出力に \(\mathcal A_R\) を厳密に作用させることはできないので、事前登録の確かめで比べ方をこう決めた）。次数の和による自己検査とは関数を分ける。末項が届く帯と届かない帯の両方を採る |
| REF 参照の模型 | `full_kernel_geometric_ref`、`full_kernel_factorial_ref`、`excess_poisson_ref` を非公開の層で作り、係数の差（2次で 1/2、C − B1 = \(\tfrac12\bar g^{*2}\)）を参照の生成器と照らす。模型ごとの打ち切り（§4.5）も確かめる: \(R=0\)、\(K_1>0\)、\(N=1\) で B1 の残りが 0、全核の2つの参照の残りが 0 でない帯を置く |

2. B1 と C の差（2次の面積で 15–17 %）と深さの相関の差（交差項の面積では 1 % 未満だが、項ごとには超過の ±20 % で、形では同じ桁になりうる。分散の項は未評価）は模型の不確かさで、数値の誤差ではない。帯の比で見分けられるかは、識別力の事前の評価（§8）で決まり、帯ごとの深さの相関の予測がなければ「未評価」と書く。
3. 核を \(E_0\) に固定する近似は、損失の大きい範囲と低い \(E_0\) で崩れる。
4. 窓の下限 \(a\) は一次線（非対称）と核の分担を決め、金属では結果が \(a\) と一次線の裾の扱いに依存する。
5. 弾性散乱（約 30 eV を越える損失）、取り込み角、表面の粗さ・酸化は模型にない。実測との差の原因を1つに帰せない。
6. 費用: 実測の条件では次数が数十から百を超え、`_fold` が支配する。高次の網の初めの幅の規則、`Panel` と `_fold` の再利用が高次の網でそのまま通るかは試走で確かめる。
7. 正孔電荷が 1 でない場合（オージェの 2 など）は `total` の核が負になりうる。警告と診断だけにする。
8. 最初の実測データの入手の可否は利用者による。
