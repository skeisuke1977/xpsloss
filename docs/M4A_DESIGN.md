## 1. 目的と範囲

均質・半無限の試料、表面法線からの出射角 0°、一様な深さの生成、弾性散乱なしの条件で、原著の式(19)のゼロ損失線と単一損失の衛星を、検出の運動エネルギーのビン積分として返す。核は M3a の `effective_cross_section_depth_averaged` をそのまま使い、物理は足さない。有限の窓の面積と下限の感度も返す。[確認 plan_final §3.1–§3.3]

- **計算の定義域:** \(0<a<b<E_0\)。\(b/E_0>0.1\) では警告する。
- **照合した範囲:** §4.6 の完了した比較の表で、必須キーがすべて合格した入口と条件だけ（登録の窓の上端は 50 eV）。試走は「訪れた条件」として記録し、照合した範囲に含めない [R2 指摘8、R3 指摘7]。
- **対象外（計画 §3.2）:** 多重散乱、軌道ごとの長さと面積の逆数の乗数、斜出射、弾性散乱、活動線がある材料のギャップ端をまたぐ窓とギャップ下の窓、\(E'\) ごとに変わる核、装置関数・寿命幅の付加、背景の差引き、逆問題、フィット、Quanty との接続、深い内殻の補正。QUEELS-XPS の完全モデルを実装したとは扱わない。

## 2. 定義

### 2.1 出発点

- [確認 Simonsen1997 p.1615 式(19)] \(J(E)\propto\cos\theta\,[F(E)+\lambda\int_E^\infty dE'\,F(E')K_{\rm sc}(E_0,E'-E,\theta)]\)。\(\cos\theta\) は括弧の全体、損失は \(E'-E\)、核の第1引数は \(E_0\)、\(\lambda\) は深さによらない文献値。両レビューが原頁の切出しで再照合した。
- [確認 同 p.1615] 式(18)の積分の前の減衰因子は、内因性が \(e^{-x/\lambda}\)、外因性が \(xe^{-x/\lambda}\)。式(18)の核は最初の1回の非弾性散乱だけを表す。REELS の重みを XPS に使う妥当性に留保がある。
- [確認 同 p.1618] 式(19)の積分は発散し、原著の Al の計算は \(E+0.05\) eV から積分した。下限への感度は小さかった。原因の説明は著者の推定。
- [確認 Yubero2005 p.045414-3 式(7)–(9)] 経路ごとの長さと、平均後の核の面積から作る乗数を使う。M4a では採らない（U1）。Ref. 13（Tougaard–Sigmund 1982）は論文庫になく、未照合。

### 2.2 ゼロ損失と単一損失 [導出。R1 指摘4は解消と判定された]

仮定: 均質・半無限、一様な生成 \(c_0F(E')\)、法線出射、弾性散乱なし、直線の軌道と一定の速度、ほかに損失しない確率 \(e^{-x/L}\)。

- \(\int_0^\infty e^{-x/L}dx=L\)、\(\int_0^\infty xe^{-x/L}K_{{\rm eff},j}\,dx=L^2K_j\)。\(c_0L=1\) として \(J(E)=F(E)+L\,(F\otimes K_{\rm total})(E)\)。
  1. 規格化した衛星 \(L(F\otimes K_j)\) は強度の単位を持つ。\(F\) に足すのは `total` の列。
  2. 点ごとの比は \(F(E)>0\) の所でだけ \(L(F\otimes K_{\rm total})/F\)。δ 線には使えない。
  3. 全領域の面積の比は \(S>0\) のとき \(w_{1,W}=LA_{\rm total}\)。\(S=0\) でも \(w_{1,W}\) は材料の量として返すが、観測の比は定義されない。
- 重みの \(L\) と乗数の \(L\) が同じ値になるのは、この導出の中だけ。
- \(LK_{\rm sc}=K_{\rm intr}+LK_{\rm extr}\) は深さによらない核の例だけ（m1 C1）。\(K_{\rm extr}=ke^{-x/d}\) なら \(kLd^2/(L+d)^2\)。
- ポアソン過程では 0回と1回の経路の積分がともに \(L\)。\(w_{1,W}\) は確率でなく、1 を超えうる（Al・1–50 eV・20 Å で 1.2545、Si・5–50 eV で 1.4712。m3c）。

### 2.3 有限の窓、一次線、出力

- **窓:** \(J_{1,j}(D)=L\int_a^bK_j\,G_D\,dT\)。窓の外は評価せず、収支にも入れない。
- **一次線（U5、U6）:** 公開の API は δ 線だけかビンだけ。強度は非負。位置とビン端は非負の運動エネルギー。内部の層B は符号つきの和を受ける。
- **\(G_D\):** δ では \(\sum_is_i\mathbf 1\{E_i-T\in D\}\)。ビン \([p,q]\)（強度 \(f\)）では、重なりの長さ \(\min(q-p,\ v-u,\ q-u-T,\ v-p+T)_+\) と \(f/(q-p)\) の積を、指数を分けて1回の丸めで作る（§3.5）。両側の外も同じ定義で直接に積分する。
- **\(J_0\):** \(G_D(0)\)。左閉右開、最後のビンは右端を含む。
- **軸（U15）:** 運動エネルギー。出力の端は非負なので、形式的な \(E<0\) の衛星は \(D_-\) に入る。束縛エネルギーへの換算 \(B-B_\star=E_\star-E\) は文書で示す。
- **単位:** \(A\) は Å⁻¹、\(w\) と \(H_j\) は無次元、ビン・外・\(H^\pm\) は \(I\)、密度は \(I\)/eV、逆数は Å。

### 2.4 返す量

| 量 | 定義 | 単位・規約 |
| --- | --- | --- |
| `window_area[j]`（11列） | \(A_j\)、誤差、予算 | Å⁻¹ |
| `single_loss_weight` | \(w_{1,W}\) と誤差 | 無次元 |
| `inverse_window_area_A` | 区間 \([1/(A+e_A),1/(A-e_A)]\) と \(1/A\)（§3.5 の厳密な丸め） | Å。\(A-e_A\le0\) なら `None` と `nonpositive_or_unresolved_area`、表せなければ `inverse_not_representable`。平均自由行程と呼ばない |
| `zero_loss`、`single_loss_{total,no_hole,hole}`、`spectrum` | \(J_0\)、\(J_{1,j}\)、\(J\)、誤差、密度と密度の誤差 | \(I\)、\(I\)/eV。負を切らない |
| `outside["low"/"high"]` | 外の \(J_0\)、\(J_{1,j}\)、\(J\)、誤差、片側の感度 | \(I\) |

8項は面積だけ、スペクトルは3成分。`total` は M3a の `total` を直接に積分する。\(LK_{\rm sc}\) の点値は返さない。\(LbK_j(b)\) は `diagnostics` だけ。

### 2.5 収支と成分 [導出]

\(\sum_DJ_0=S\)、\(\sum_DJ_{1,j}=SLA_j\)、\(\sum_DJ=S(1+LA_{\rm total})\)。面積でも各領域でも `total = no_hole + Q_h·hole`。差と丸めの上界を `diagnostics.balance` に残し、補正しない。**収支は外を残差で埋めても通るので、合格の根拠にしない**（各ビンと外は参照と直接に比べる）。

### 2.6 下限の感度 [導出]

\(H_j=LaK_j(a)\)。一般の片側の感度は \(H^\pm_{j,D}=LaK_j(a\pm0)G_D(a\pm0)\)。公開の M3a の核は窓の下端で連続。全領域の和は左右とも \(S\,LaK_j(a\pm0)\)。1桁下げた増分は \(L\int_{a/10}^aK_j\,dT\)（\(c/T\) で \(H\ln10\)、定数で \(0.9H\)）。Al・20 Å・\(a=1\) eV で \(LaK_{\rm total}=0.0302\)（成分 \(+0.187\)、\(-0.157\)）、Si・\(a=5\) eV で 0.160（m3c）。

## 3. 数値の方法

### 3.1 構成

- **層A `_loss_panels`:** 核 `kernel(T, side) -> (values[11,n], errors[11,n])`、窓、**解像の尺度**（§3.2）、精度を受け、区分多項式の表現を返す。
- **層B `_fold`:** パネル、一次線、出力の端、乗数を受け、§2.4 の量と誤差を作る。核を新しく評価しない。
- **駆動:** 層A と層B を交互に呼び、§3.4 の条件を満たすまで細分する。**初期の区切りは出力と独立で、細分は出力に依存する** [R2 U3]。

### 3.2 解像の尺度と成功の契約 [統合。R1 指摘1、R2 指摘1・2。U19]

**(1) 成り立つこと [導出。R2 指摘1が正しいと判定。統合で確認 m6 V3、V4]**

- 誘電の係数は \(S=\sum_iA_i/D_i\)、\(D_i=W_i(q)^2-T^2-i\Gamma_iT\)、\(W_i=E_i+d_iHq_{\rm arg}^2\)、\(R=S/(2-S)\)、\(C=2S-R\) [確認 model.py、xps_fixed_depth.py 348行]。`Oscillator` は \(A_i\ge0\)、\(\Gamma_i>0\)、\(d_i\ge0\) を課す。
- **実の \(q\) を固定**すると、\(T=x-iy\)（\(x>0\)）で \({\rm Im}\,D_i=x(2y-\Gamma_i)\)。\(|y|<\Gamma_{\min}/2\) では \(D_i\ne0\)、\(S\ne1,2\)。無作為の 3000 組でも、根の距離の最小は \(\Gamma_{\min}/2\) の 1.0000 倍だった。
- ギャップでも、実の \(q\) を固定すれば両側の半帯で同じことが言える [R2 指摘1 の補強]。
- **全振動子が無分散**（\(d_i=0\)）なら、極は \(q\) によらず \(T\) で固定され、運動量の積分の後も同じ位置に残る。その位置は計算できる。

**(2) 成り立たないこと [R2 指摘1。統合で再現 m9 R1]**

- **`k_total` の複素の \(q(z)\):** 合成の \((3,3450,0.1,96)\) で、固定した \(k_\parallel\) の表面の極が \(50.0000095507+0.0235849i\) eV に出る。距離は \(\Gamma/2\) の 0.472 倍。第2版の条件 \(c\,{\rm Re}W\le1\) は入力の制約になく、この根の付近では 1.56。
- **動く積分端:** 下端で \(W_-(z)\) が \(W_-(x)=x\) を横切ると、端の \(D=0\) の根の距離は弱減衰で \(\Gamma/(2|1-W'_-(x)|)\) になる [導出を確認: \(D\approx2x(W'-1)\delta-i\Gamma x\)]。端の \(W_-\) は次のとおり。
  - `k_total`: \(E_i+d_iu(T)\)、\(u=(\sqrt{E_0}-\sqrt{E_0-T})^2\)。
  - `k_parallel`: \(E_i+d_i(u-T^2/4E_0)\)。
  - 数値の確認（再現）:
    - `k_parallel`、\(x=50\): \(W'=2.97186\)、根 \(50.00003248+0.02535665i\)。公式の値は 0.0253567 で一致、\(\Gamma/2\) の 0.507 倍。
    - `k_total`、\(x=990\): \(W'=10.944\)、根の虚部 0.00502793（0.101 倍）。
- **\(T=E_0\):** 無分散の 13a でも \(\log(q_+/q_-)=2\,{\rm asinh}\sqrt{(E_0-T)/T}\) [導出を確認]。窓 \([900,E_0-10^{-3}]\) の1パネルで補間の誤差は \(5.2\times10^{-3}\)、\(E_0\) へ比 2 で刻んだパネルで \(6.6\times10^{-14}\)（m9 R6）。
- **一般の定理は立てない。**

**(3) 局所の解像の尺度（M3a を呼ぶ前に計算する）**

候補の特異点 \(z_s\) を、次の手順で集める。

1. **候補の根（ギャップなしの材料）[R3 指摘3]:** \(s=\sqrt{E_0-z}\)（主値。窓の実区間では \(s>0\) で、そこから続く枝）と置く。
   - 端の運動量の式:
     - `k_total` では \(Hq_\pm^2=(\sqrt{E_0}\mp s)^2\)。
     - `k_parallel` では、そこから \((E_0-s^2)^2/(4E_0)\) を引く。
   - \(z=E_0-s^2\) とすると、各 \(D_i\) と、分母を払った連成の \(2-S\)、\(1-S\) は \(s\) の多項式になる。
     - **次数の上限:** `k_total` では \(W_i(s)\) が2次、\(D_i(s)\) が4次で、連成の多項式は \(4n\) 次。分散ありの `k_parallel` では \(W_i(s)\) が4次、\(D_i(s)\) が8次で、連成の多項式は最大 \(8n\) 次（振動子 \(n\) 本）[確認の指摘1]。
   - 多項式の**全根**を求める。\({\rm Re}\,s>0\) は下端、\({\rm Re}\,s<0\) は上端の根である。
   - **多項式の変数 [試走の指摘2]:** binary64 では、\(s\) や \(\sigma=s/\sqrt{E_0}\) の多項式の根は悪条件である。Si の表面の族で、`k_total`（12 次）の真の3根のうち2つ、`k_parallel`（24 次）の1つを落とし、0.9–1.6 eV ずれた未確認の点を返した（trial `t16b`–`t16d`。真の根は有理数の係数と 50 桁で求めた）。下端の根は \(t=1-s/\sqrt{E_0}\)、上端の根は \(t=1+s/\sqrt{E_0}\) の多項式（端のまわりの展開）で求める。この形では同じ3根が \(7\times10^{-11}\) eV 以内で求まった（`t16e`）。最高次の係数が厳密に 0 になる場合（\(d_i=1\) など）は、その係数を落として次数を下げる。
   - **無分散の振動子だけの材料**は \(W\) が定数なので、\(z\) の多項式（\(2n\) 次）で直接に解く。これは \(q\) によらない固定の極の列挙になる。
   - **根の対応 [確認の指摘1]:** 各根を元の式で Newton 法で磨いた後、族・端ごとに、多項式の根と磨いた根を多重度を数えて1対1に対応させる。
     - 磨いた根が別の多項式の根に移った場合（二つの多項式の根が一つの磨いた根に集まり、多重度で説明できない場合）は、その根の磨きを捨て、多項式の根のまま元の式で確かめる。
     - 確かめられなければ、その根を「未確認の候補」として許容の規則には使い、実行の区分を `computed_candidates_only` に落として警告を出す。
     - 例（CE6）: 第2線の中心を 10.0000001 eV にした二重の線では、\(z\) の多項式から \(8.3516466041-0.5i\) と \(9.9874922278-0.5i\) を得る（レビューと一致。m11 G）。第4版の手順では Newton 法が後者を前者へ移し（移動 1.64 eV）、残差の検査を通ったまま後者が消えた。後者は体積の極から \(5\times10^{-8}\) eV の位置にあり、元の式の尺度つきの残差は \(1.5\times10^{-6}\) で binary64 では確かめられない（m11b）。そのため区分は `computed_candidates_only` になる。
2. **凍結する選別の規則:**
   - **確認:** 連成の族（\(2-S\)、\(1-S\)）では、元の式の残差が \(10^{-8}(1+\sum_i|A_i/D_i|)\) 以下。体積の族（\(D_i=0\)）では \(|D_i|\le10^{-8}\sigma_i\)、\(\sigma_i=|W_i|^2+|z|^2+\Gamma_i|z|\)（連成の基準は体積の極で発散し、常に通るため）[試走の指摘6]。
   - **相殺:** 分母を払った根で、ある \(|D_i|\) が \(10^{-10}\sigma_i\) 以下のものは相殺として除く。
   - **重複:** \(|\Delta z|\le10^{-9}(1+|z|)\) で同じ端の根を一つにする。
   - **採用:** 窓までの距離 \({\rm dist}(z,[a,b])<b-a\) の根。
   - **原点の近く:** 特別な除外はしない。下の許容の規則と低損失の刻みが扱う。\(|z|<a/2\) の根は診断に「原点近傍」として残す。
3. **ギャップのある材料:** 連成の係数をギャップなしの式で近似し、上と同じ多項式で候補を作る。ギャップを含む複素の続きは扱わない（T16 で記録だけ）。
4. **刻み:**
   - 低損失: ギャップなしは \(a\cdot2^k\)、活動のギャップは \(g+(a-g)2^k\)。
   - 上端: \(E_0-(E_0-b)2^k\)。
   - 比は 2。
5. **幅の上限:** \(\Gamma_{\min}\)（内部の滑らかさの目安。根拠は (1) の固定 \(q\) だけ）。
6. **許容の規則 [統合。第3版の「候補ごとの刻み」を置き換えた]:** 各パネル \(P\) とすべての候補 \(z_s\) について、\({\rm dist}(z_s,P)\ge|P|/2\) を課す。
   - 満たさないパネルは、M3a を呼ぶ前に binary64 の中点で二分し、満たすまで繰り返す。これで近い候補のまわりは自動的に等比に細かくなる。
   - 上限 \(\Gamma_{\min}\) は、距離 \(\Gamma_{\min}/2\) の極に対するこの条件の境の場合である。
   - 単一の Lorentz では、パネル幅が極の距離の 2 倍のとき、1パネルの相対誤差は \(3.4\times10^{-10}\)（m6 V2）。一般の余裕を保証するものではない。

**確認（m10 C、D）:**
- 二重の線 \((10,30,1,0)\)、\((10.05,30,1,0)\) の表面の根を、多項式から2つとも得た（\(8.38110239-0.5i\) と \(10.01297272-0.5i\)、残差 \(7\times10^{-15}\) と \(2\times10^{-11}\)）。第3版の Newton 法の探索は前者だけを返した [R3 指摘3を再現]。
- \(s\) の多項式は、CE2 の根 \(50.0000324820+0.0253566517i\)、CE3 の根の虚部 0.00502793、上端の対照の距離 0.048808122・0.048793581 をすべて再現した。
- Al と Si の窓の中の候補の距離は、\(\Gamma_{\min}/2\) の 1.00006–1.008 倍（`k_parallel` の Al で 1.000065）。

**(5) 成功の契約と `resolution_basis` [R2 指摘1、R3 指摘3]**

- **どの場合も、成功は「判定対象の全出力で推定誤差が予算の内」という意味である。**M3a・固定深さと同じ基準で、証明された上界ではない。帯の中の \(|K|\) の上界は求めず、M3a の点の誤差も推定である。
- 尺度の根拠の強さを `diagnostics.resolution_basis` に記録する。
  - `fixed_poles_enumerated`: 全活動線が無分散でギャップなし、かつ (3) の 1 の列挙で全根を確かめ、根の対応が多重度を含めて取れた。
  - `endpoint_roots_enumerated`: 分散ありでギャップなし（Al）、かつ端の全根を同じ条件で確かめた。運動量の内部での極の挟み込みは解析していない [推論]。
  - `computed_candidates_only`: ギャップのある材料（Si、N1、N2）、または列挙で確かめられない根があった実行。探索だけで終えた実行もここに落とす。
- 3つ目と照合の範囲の外では警告を出す（U19 (i)）。

**(6) 解析の核の層の契約（試験と参照の専用）[R2 指摘2]**

- 呼び出し側は必ず申告する。
  - 跳びと折れ点（片側の値を返す）。
  - 実軸に近い特異点の（中心、半幅）、または最小の半幅。
  - 整関数の速い振動や狭い山の**最小の変動の尺度**（幅の上限 \(2\times\) 尺度）。
- 申告のない特徴は契約の外。レビューの反例（RA8a）は、中心と半幅を申告すると、許容の規則で **41 パネル**になる（m11 J。第4版の 47 枚は旧い区切りの値）。確認の再計算では、面積の絶対差 \(4.54\times10^{-18}\) Å⁻¹、補間と検証の残差の推定の和 \(1.30\times10^{-11}\) Å⁻¹ で予算 \(10^{-10}\) の内だった。最小の半幅だけなら拒否する（RA8b）。

**(7) 各パネルの推定と検証の点 [F、R2 指摘2]**

- Chebyshev–Lobatto の 17 点で補間 \(p_{17}\) と入れ子の \(p_9\) を作る。補間の推定は \(e^{\rm int}_{j,P}=\int_P|p_{17}-p_9|\)（40点 Gauss の近似値）。厳密な上界が要る所では係数の差の和 \(s_{j,P}\) を使う。
- **検証の点 [R3 指摘2]:** 各パネルの第1種 Chebyshev の 16 点で核を評価する。
  - **生の残差** \(\rho_{j,P}=\max_m|\widehat K_j(\tau_m)-p_{17}(\tau_m)|\) と、**検証の点の不確かさ** \(\epsilon_{j,P}=\max_me_j(\tau_m)\) を別々に記録する。
  - 予算には \(r_{j,P}=\max_m(|\widehat K_j(\tau_m)-p_{17}(\tau_m)|+e_j(\tau_m))\)（Å⁻¹ eV⁻¹）を使う。§3.4 で \(|P|\)、\(L|c|\sup_c|G|\) により全出力に伝えてから判定する。
  - 第3版の \((\cdot-e)_+\) は、点の不確かさを許した最小の食い違いで、検証の点の情報を消しうる。
  - レビューの注入の例（[2,3] の Lorentz、最小の半幅 0.5 を申告、Lobatto 点に \((\widehat K,e)=(0,K)\)、検証の点に \((K,K)\)）で、推定は第3版の式で \(9.99999999890\times10^{-11}\)（予算 \(10^{-10}\) の内、実誤差 \(1.000000000143\times10^{-10}\)）、第4版の式で \(3.56\times10^{-10}\)（予算の外）になる（m10 B）。RA14 として登録する。
  - 検証の点の不確かさは点の誤差と重なって二重に数えうるが、安全側に残す。費用は約2倍。

### 3.3 層B　セルの積分 [F、C、R1 指摘3、R2 指摘4・5]

1. **セル:** 出力ごとに、\(G_y\) の折れ点と跳び \(t=p-d\)、窓の端、パネルの端で分ける。
2. **差だけで計算する:** \(p-d\) は TwoSum で厳密な（値、残差）にし、順序・所属・局所の幅に残差を使う。例えば \(1000-0.1-{\rm fl}(999.9)=2.27\times10^{-14}\)（m8）。
3. **片側の値:** セルの両端の \(G\) と核は、セルの内側からの極限を使う。キャッシュのキーは解析の核では \((T,{\rm side})\)、M3a の核では \(T\)。
4. **セルの重み:** \(\omega_{c,q}=\int_cG_y\ell_q\,dT\) を 9 点の Gauss で作る（17次以下で厳密）。重みは負になりうる（[2,2.02] で3番目の基底は \(-0.0016024037678\) eV）。
5. **積と重みの丸め:** 積の誤差には交差項を含める（\(|x|e_y+|y|e_x+e_xe_y+\epsilon|xy|\)）。重みの丸めは積の絶対値の和から作り、\(\sum_q|\delta\omega_q|(|K_q|+e_q)\) を入れる。
6. **端の誤差:** 丸めで潰れた折れ点や、残差で決めた局所の幅では、\(\int|\delta G|\,dT\) にその区間の核の包絡を掛けて積む。
7. **両側の外:** その領域に入る一次線の部分だけから作る。累積の差や残差を使わない。
8. **セルの数:** 非空のセル（厳密な幅が正）を数える。出力の領域（各ビンと両側の外）ごとに、窓の全体を \(G_y\) の折れ点と跳び、窓の端、パネルの端で区切り、厳密な幅が正の区間をすべて数える。\(G_y=0\) の区間も数える [試走の指摘8]。
   - 初期の数は端の差の配列を作る前に検査する。`max_cells` を超えれば `cell_limit_exceeded`。
   - 細分の各段の前にも検査する。途中で超えれば `cell_limit_reached`。

### 3.4 誤差と成功の条件 [計画 §3.4。R2 指摘2・3で改訂。U4]

| 項 | 面積（Å⁻¹） | 衛星の領域（\(I\)） |
| --- | --- | --- |
| 補間 \(e^{\rm int}\) | \(\sum_Pe^{\rm int}_{j,P}\) | \(L\sum_c\sup_c|G_y|\min(|c|s_{j,P},e^{\rm int}_{j,P})\) |
| **検証の残差 \(e^{\rm ver}\)** | \(\sum_P|P|\,r_{j,P}\) | \(L\sum_c|c|\sup_c|G_y|\,r_{j,P(c)}\) |
| 点 \(e^{\rm pt}\) | \(\sum_P\sum_qw^{\rm CC}_{P,q}e_j(T_q)\) | \(L\sum_c\sum_q|\omega_{c,q}|e_j(T_q)\) |
| 端 \(e^{\rm edge}\)、丸め \(e^{\rm rnd}\) | 0、積の絶対和×\(\epsilon\)×定数 | §3.3 の 6、同×\(L\) |

\(e_y=e^{\rm int}+e^{\rm ver}+e^{\rm pt}+e^{\rm edge}+e^{\rm rnd}\)。判定対象と予算:

| 判定対象 | 予算 |
| --- | --- |
| 面積 11列 | \(\max(\varepsilon_{{\rm abs},A},\varepsilon_{\rm rel}|A_j|)\)（Å⁻¹） |
| 各ビンと外の \(J_{1,j}\)（3成分）と \(J_0\) | \(\max(\eta S_{\rm abs},\varepsilon_{\rm rel}|y|)\)（\(I\)） |

- **成功:** 判定対象の全量で \(e_y\le B_y\)。全一次線が 0 のときの \(e=B=0\) は成功とし、比は `null` と `zero_budget_zero_error`。
- **回帰の条件 [R2 指摘2、統合で確認 m9 R3]:** レビューの Chebyshev の例を使う。核 \(\kappa[1-\mathcal T_{32}(2T-5)]\)（[2,3]、\(\kappa=4\times10^{-11}\)）、δ 1000 eV、表示 [997,998]、\(L=100\) Å。
  - 面積の推定は \(8\times10^{-11}\le10^{-10}\) で、面積だけなら通る。
  - 衛星の推定は \(8\times10^{-9}>10^{-9}\) で細分を要求する。
  - 3回の二分の後、面積 \(4.0039101\times10^{-11}\)、衛星 \(4.0039101\times10^{-9}\) で正しく成功する。
  - 残差を伝えない誤った版は、衛星 0 で成功する（RA12）。
- **検証の点の不確かさの回帰 [R3 指摘2]:** RA14（§3.2 (7) の注入の例）では、推定 \(3.56\times10^{-10}\) が予算 \(10^{-10}\) を超え、成功しない。
- **停止 [R2 指摘3]:** 現在の節点の床では止めない。点の誤差の和は細分で大きく変わりうる（尖った点の誤差で 17 点の和が 0.0982、二分の後に 0.00196。m9 R4）。止まるのは次の場合だけである。
  - 次の段の二分で `panel_limit` を超えるとき（評価の前に検査する）。理由はその時点の最悪の出力で分ける。
    - 点の誤差だけで \(B\) を超えていれば `kernel_error_exceeds_budget`。
    - ほかは `loss_budget_not_met`（`dominant_part`: `interpolation`、`verification`、`kernel_point_error`、`edge`、`rounding`）。
  - セルの上限に達したとき（`cell_limit_reached`）。
  - 入力から決まる設定の不正。\(\varepsilon_{\rm rel}<64\epsilon\) は計算の前に `invalid_settings` にする。
- **細分:** 失敗している出力について、そのパネルの寄与が \(B_y\) を台の幅で按分した値の半分を超えるパネルを二分する。
- **記録:** 判定対象の全量の5項・予算・比と、最大の比の出力を `diagnostics.error_budget` に残す。
- **既定（U11。試走 §3 で確かめ、この値で凍結する案）:** \(\varepsilon_{\rm rel}=10^{-6}\)、\(\varepsilon_{{\rm abs},A}=10^{-10}\) Å⁻¹、\(\eta=10^{-9}\)、`panel_limit` 400、`max_cells` \(2\times10^6\)。M3a の精度は API の既定（\(10^{-12}\)、\(10^{-9}\)、200）、CLI は設定の `integration`。
  - `panel_limit` は M3a の点の数の上限も決める。点の数は補間点と検証点を合わせて \(32n+1\) で、400 枚なら 12,801 点。1点 4 ms（Al）・8 ms（Si）の仮定で、CPU 51 秒・102 秒に当たる [推測]。点の数だけの別の上限は置かない。
  - M3a の点の誤差の余裕は、9–11 点の台形の概算で約3桁（m3b）。
  - \(\eta\)、`panel_limit`、`max_cells` の余裕はこの試算から決まらない。

| \(w_{1,W}\) | \(Le_{A,\rm total}+\epsilon|w|\) |
| 逆数の区間 | \(A\) と \(e_A\) を厳密な有理数として \(1/(A\mp e_A)\) を求め、下端は下へ、上端は上へ丸める。通常の引算と除算の後に `nextafter` を1回掛けても届かない例がある（\(A=0.6519427672317586\)、\(e_A=0.06645324737206787\)。m9 R7） |
| \(H_j\) | \(Lae_j(a)+2\epsilon|H_j|\) |
| \(H^\pm_{j,D}\) | \(La\,[e_j(a)|G|+|K_j(a)|e_G+e_j(a)e_G]\)＋丸め（交差項を含む） |
| 密度 | \(e_y/\Delta u+\epsilon|y|/\Delta u\) |

- **指数を分けた積と商:** \(G\)、\(J_0\)、密度は、仮数と指数を分けて1回だけ丸める（`frexp`、`ldexp`、または局所の有理数）。例えば一次ビン \([0,2^{900}]\)、強度 \(2^{900}\)、表示 \([0,2^{-200}]\) では、比を先に取ると 0 になるが、正しい値は \(J_0=2^{-200}\)（m9 R7）。逆の順序で失う例もある。
- **強度の範囲:** 正の強度は \([2^{-900},2^{900}]\)、\(S_{\rm abs}\le2^{900}\)（ほかは `invalid_primary`）。範囲の内でも、表せない結果は `nonfinite_output` で明示する。

### 3.6 M3a の呼び出しと費用

- 段ごとにまとめて呼び、毎回 \(a\) と \(b\) を番兵に含める（事前検査の \(q_{\min}\) を揃える）。値は呼び出しの組み方によらずビット単位で同じ（m3a）。上流の警告は出所と節点を付けて重複を除く。
- 候補の根の計算は M3a を呼ばない。統合の試算では、全材料の多項式の根と許容の規則の計算が、合わせて数秒以内だった [m10 E、試算の全体の時間による推測]。
- **初期の M3a の点の数（補間点 \(16n+1\)＋検証点 \(16n\)）[R3 指摘4]:**

| 材料と窓 | 許容の規則（第4版） | 第3版の規則 |
| --- | ---: | ---: |
| Al・[1,50] | 35 枚、1,121 点 | 55 枚、1,761 点 |
| Si・[5,50] | 15 枚、481 点 | 86 枚、2,753 点 |

  - 細分の段がこれに加わる。
  - 1点 4 ms（Al）・8 ms（Si）の仮定で、初期だけで CPU 4.5 秒と 3.8 秒 [推測]。第3版の規則なら 7.0 秒と 22 秒。試走の実測は1点 1.4 ms（Al）・4.9 ms（Si）で、共鳴の近くの細い線では 3–16 ms だった（T1）。候補の根と許容の規則は合わせて 0.05 秒以下だった（T10、T15）。
  - Fable の試算は CPU 2.0 秒に対し経過 7.9 秒だったので、経過時間は別に測る。
  - 細い線では \((b-a)/\Gamma_{\min}\) に、近い候補では二分の段数に比例して増える。
- **T10・T15 で別々に測る:** 候補の根の計算、許容の規則の二分、M3a の呼び出し（点の数と時間）、層B のセルの計算。CI の経過時間の見積もりは、この実測で更新する。

### 3.7 選ばなかった方法

| 方法 | 理由 |
| --- | --- |
| \(\Gamma_{\min}/2\) の帯を一般に主張する（第2版） | `k_total` と動く端の反例（R2 指摘1、m9 R1） |
| M3a の運動量の変数を全運動量に取り替えて、誘電因子と端を分ける（R2 指摘1 の例示） | M3a を変えない範囲の外。端の共鳴は §3.2 (3) で直接に計算する |
| 証明された誤差の上界（U19 (iii)） | 複素の \(T\) での M3a の評価と区間演算が要る（§9 U19） |
| \(G\) の全折れ点を損失方向の区切りにした Gauss–Kronrod | 費用と核の節点の出力依存。R-B は \(E'\) を外側にした Gauss–Legendre |
| 現在の節点の床で止める（第1・2版） | 細分で減りうる（m9 R4） |
| 候補ごとに等比の区切りを必ず足す（第3版） | 上限ですでに足りる候補にも区切りを足し、Si で 15 枚が 86 枚になる。許容の規則は近い候補だけを細かくする |
| Newton 法の探索だけで候補を集める（第3版） | 根を落とす（二重の線の例）。ギャップのない材料では多項式で全根を求める |
| 寄与が予算未満の細い線を除く | 根拠の作り方が未確立 |
| \(\ln T\)、原始関数の差、節点則、累積の差、FFT、M3a の内部 | 第1版と同じ理由 |

### 4.3 警告

- 出所を付ける。`source: "xps_depth_averaged"` は継承した警告で、“Only point values are returned.” は M3a の点値の関数についての文である。`source: "xps_single_loss"` は新しい警告。
- **常に:** 窓の外を含まないこと、\(w\) は確率でないこと、核を \(E_0\) に固定すること、一次線は内因性の損失を含まないとすること。
- **条件つき:**
  - \(b/E_0>0.1\)。
  - \(a<\) 一次線の最小のビン幅。
  - \(E_0\) が正の強度の点の最小と最大の間にない（U16）。正の強度がなければ、台に依る警告は適用しない [R2 指摘8]。
  - 台の下端 \(<b\)。
  - `resolution_basis` が `computed_candidates_only`（U19 (i)）。
  - 照合の外。
  - \(Q_h\ne1\)。

### 4.4 CLI

```powershell
xpsloss xps-loss-window-area config.json --loss-window-eV 1 50 --weight-length-A 20 --weight-length-source "design example" --epsilon-momentum k_total --out runs/area
xpsloss xps-single-loss config.json --spectrum spectrum.json --loss-window-eV 1 50 --weight-length-A 20 --epsilon-momentum k_total --out runs/spec
```

- **任意の引数:** `--hole-charge`、`--theta-deg`、`--epsrel`、`--area-epsabs`、`--panel-limit`、`--kernel-epsabs/-epsrel/-limit`。`xps-single-loss` だけ `--spectrum-epsabs-fraction` と `--max-cells` を受ける。面積のコマンドにスペクトルの引数を与えたら入力エラー。
- **設定ファイル:** `loss_grid_eV` は検証するが使わない（`config_loss_grid_used: false`）。
- **`spectrum.json`:** 一次線と出力の端を同じ1つの JSON に置く（U8）。
  - `schema`、`axis: "kinetic_energy_eV"`、`primary`（`kind` と来歴）、`output_edges_eV` を持つ。
  - `{"min","max","step"}` の形は専用の検査にかける: \(0\le\)min\(<\)max、区間数が整数、展開の後に狭義の増加。展開した配列のバイト列の SHA-256 を記録する。
- **失敗:** `main` の専用の変換で、新しい `reason`、全属性、上流の公開の属性を stderr の JSON に入れる。非有限の値は文字列にする。
- **出力:**
  - `window_area.csv` と `single_loss_spectrum.csv`。全 CSV を書いた後に `run.json` を完了印として書く。
  - 両 CLI の実効の引数から、API で列と外を再生する試験を置く。

### 4.5 `run.json` と `capabilities`

- **`run.json`:** 同定と再現、`spectrum_definition`、`primary`、`results`、`diagnostics` の各欄を持つ。
  - `primary` は、正の強度の点の最小・最大（なければ `null`）と \(E_0\) との差を記録する。
  - `diagnostics` は次を記録する。
    - `resolution_basis` と候補の根（\(z\)、出所の族、端、確認の残差、原点近傍の印、列挙か探索か）。
    - 必要なパネル数、刻み、許容の規則で二分したパネル。
    - 検証の点の生の残差 \(\rho\) と不確かさ \(\epsilon\) の最大（別々に）、\(r\) が加わった出力。
    - 誤差の5項。
  - 面積だけの実行では、一次線の欄を `null` にする。
- **`capabilities`:** `supported` の既存の要素と順はそのままにし、末尾に足す。既存のブロックは等しいままにする。

### 4.6 照合の表示 [R1 指摘6、R2 指摘6。U10]

- **2つの表:** (a) 登録表と、(b) **完了した比較の表**（版、ハッシュ、ケース、入口、対象のキー、判定 `pass`・`fail`・`no_reference`・`unresolved`・`not_run`）を持つ。照合の判定は (b) だけから作る。
- **入口ごとの一致:** 正規化した数値列の等号で判定する（空白や来歴の文字列は比べない）。
  - 面積の関数: 材料、\(E_0\)、\(L\)、\(m\)、\(Q_h\)、窓、精度。
  - スペクトルの関数: 上に一次線と出力の端を加える。
- **群と必須キー:**
  - `areas` は面積 11、\(w\)、逆数の区間、\(H\) 11。逆数の区間は2通りに比べる: 参照の面積と不確かさとの整合、実装が報告した \(A,e_A\) からの端の変換。
  - `spectrum` はビンと外の5量と片側の感度。
  - 群の全必須キーが `pass` のときだけ `matched`。欠けたキーは `no_reference` と理由を残す。
  - 核の条件だけが合う別の一次線の実行は `kernel_conditions_checked`。
  - 試走（T 系）は完了した比較の表に入れない。`matched` を付けるのは、表の入口と条件のうち必須キーがすべて `pass` のものだけ [R3 指摘7]。
- **別の欄:** R-A の演算の照合、実材料の照合、`resolution_basis`、`physical_validity: "not_established"`、計算の `status`。

### 6.8 許容幅と判定 [R1 指摘5で確定。R2 で解消と判定された]

- **精度の比較:** \(|y-r|+u_r\le d_{\rm abs}+d_{\rm rel}|r|\)。キーごとに単位、床、最大の幅を凍結する（面積は Å⁻¹、\(w\) と \(H\) は無次元、逆数は Å の両端、ビン・外・\(H^\pm\) は \(I\)）。
  - R-A は \(d_{\rm rel}=\varepsilon_{\rm rel}\)（RA13 は実行の \(10^{-13}\)）。RA6・RA6b の小さい裾、RA3 の `hole` には専用の置き換えの幅を使う。
  - R-B は \(d_{\rm rel}=\max(8f_r,\varepsilon_{\rm rel})\)、参照の有効の条件は \(u_r\le\)（幅）\(/4\)。\(d_{\rm rel}>10^{-4}\) なら凍結しない。
  - 比較幅は実装の \(e_y\) と独立に決める。
- **推定の検査（三値）:** \(d=|y-r|\)、\(e=e_y+f_{\rm fp}\)。
  - \(d+u_r\le e\) なら「推定が覆う」。
  - \(d-u_r>e\) なら「過小推定」（不合格）。
  - その間は「照合未確定」。
- `hole`、`no_hole`、`total` は別に判定する。

### 6.9 時間の上限

- CI の増分は経過時間で 60 秒以内、R-B の全件は1コアの経過時間で 2 時間以内。試走では、CI は §6.6 の規則のもとで 40–50 秒、R-B の全件は CPU 5–10 分の見込みだった。CI が 60 秒を超えたら、V の格子を間引く（例えば 4 点おき）。
- 追加の点は、比較を開く前に打ち切る。
- 必須が収まらなければ、旧版を残して再登録する。

## 7. リスクと未確定の点

1. **成功の保証の範囲:** どの場合も推定であって上界ではない。`computed_candidates_only`（Si を含む）では候補の完全性の根拠がない（§3.2 (5)）。
2. **候補の根の計算:** ギャップのない材料では端のまわりの変数 \(t\) の多項式で全根を求める（§3.2 (3)）。\(s\) の形の悪条件は試走で確かめたが（Si で根を落とした）、\(t\) の形の安定性は Si の3根と CE の入力でしか確かめていない。ギャップのない3線以上の材料で `endpoint_roots_enumerated` が取れるかは未確認。ギャップのある材料は、連成をギャップなしの式で近似する（T16 で記録するだけ）。運動量の内部での極の挟み込みは解析していない。
3. **解像の費用:** 細い線では \((b-a)/\Gamma_{\min}\) に比例し、N1 は既定では計算の前に止まる。近い候補では二分の段が増える。許容の規則は境の場合（Al の `k_parallel` で距離が上限の半分の 1.000065 倍）に余裕が小さい。
4. **節点の分離の検査:** 幅がおよそ 208 ulp より狭いパネルは作れないので、極端に細い特徴は `panel_width_unresolved` になる（誤った成功は返さない）。
5. **低損失の発散**（Simonsen1997 p.1618）: 窓を必須にし、感度を成分ごとに返す。
6. **\(\lambda\) の読み方、Ref. 13 の未照合。**
7. **費用の実測がない:** 出力ごとの判定、検証の点、候補の刻みの M3a での実測。
8. **M3a の1点の未収束で全体が止まる。**
9. **核を \(E_0\) に固定:** m7 は2材料・指定の窓・固定長での**面積の局所の感度**（\(d\ln A/d\ln E_0\) は Al で −0.44、Si で −0.40）。個々のビンの固定核の誤差を測ったものではない [R2 指摘8]。
10. **二重計上は判定しない。照合の表示は、ほとんどの実行で照合の外になる。**
11. **範囲:** 計算の定義域は \(b<E_0\)（\(b/E_0>0.1\) で警告）。照合した範囲は、完了した比較の表で必須キーがすべて合格した入口と条件だけ（登録の窓の上端 50 eV）。試走は訪れた条件として記録する。原著の図9との比較はしない。
